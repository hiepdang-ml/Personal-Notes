\chapter{Introduction}
\label{ch:introduction}

A pattern recognition system learns a function that maps an input vector $\mathbf{x}$ to an output $\mathbf{y}$ using a set of training data. Once trained, the system is applied to previously unseen inputs, and its ability to produce accurate outputs for data that differ from the training examples is known as \textit{generalization}, a central goal of pattern recognition. Before being passed to the learning algorithm, raw input data are often \textit{pre-processed} or transformed into a more useful representation, a process sometimes called \textit{feature extraction}. Such transformations can reduce irrelevant variability, lower dimensionality, and improve computational efficiency while preserving information important for the task. The same pre-processing procedure must be applied consistently to both training and test data, and care must be taken not to discard information that is necessary for accurate prediction.

Pattern recognition problems can be broadly divided into \textit{supervised learning} and \textit{unsupervised learning}. In supervised learning, each training input vector $\mathbf{x}$ is paired with a corresponding target output $\mathbf{t}$, and the goal is to learn a mapping from inputs to targets. If the target belongs to one of a finite set of discrete categories, the problem is called \textit{classification}; if the target consists of one or more continuous variables, it is called \textit{regression}. In unsupervised learning, the training data contain only input vectors without associated target values, and the goal is instead to discover structure in the data. Typical unsupervised tasks include \textit{clustering}, which groups similar observations, \textit{density estimation}, which models the distribution of the data, and \textit{dimensionality reduction}, which represents high-dimensional data in a lower-dimensional space for analysis or visualization.

\textit{Reinforcement learning} is concerned with learning how an agent should act in an environment in order to maximize a cumulative reward. Unlike supervised learning, the agent is not provided with the correct output for each situation, but instead learns through interaction, trial and error, and feedback in the form of rewards. Because an action may influence not only the immediate reward but also future states and rewards, reinforcement learning often involves a \textit{credit assignment problem}: determining which earlier actions were responsible for a later outcome. A central challenge is balancing \textit{exploration}, in which the agent tries new actions to gain information about their consequences, and \textit{exploitation}, in which it selects actions that are already known to produce high rewards. Effective reinforcement learning requires an appropriate trade-off between these two behaviors.

\textit{Overfitting} occurs when a model becomes too closely adapted to the training data, capturing not only the underlying relationship in the data but also random fluctuations or noise. An overfitted model can therefore achieve very low training error while performing poorly on previously unseen data, indicating weak \textit{generalization}. This typically happens when the model is unnecessarily complex relative to the amount or quality of available training data. For example, in polynomial regression, increasing the polynomial order $M$ increases the flexibility of the fitted function. If $M$ is made sufficiently large, the polynomial can pass exactly through all training points and drive the training error to zero. However, the resulting coefficients may become very large and the fitted curve may oscillate strongly between training points.

For a fixed model complexity, increasing the size of the training set generally reduces the risk of \textit{overfitting}, because the model is constrained by more observations and has less freedom to fit random fluctuations in individual data points. Conversely, with limited training data, highly flexible models are more prone to overfitting. Rather than controlling complexity only by reducing the number of model parameters, a common approach is \textit{regularization}, which modifies the training objective by adding a penalty for large parameter values. For example, $L_2$ regularization minimizes

\begin{equation}
    \widetilde{E}(\mathbf{w}) = \frac{1}{2}\sum_{n=1}^{N}\left\{y(\mathbf{x}_n,\mathbf{w}) - t_n \right\}^{2} + \frac{\lambda}{2}\|\mathbf{w}\|^{2},
\end{equation}

where $\lambda$ controls the strength of the regularization and $\|\mathbf{w}\|^2 = \mathbf{w}^{\mathrm{T}}\mathbf{w}$ is the squared $L_2$ norm of the parameter vector. The penalty discourages excessively large weights and therefore limits the effective flexibility of the fitted function. This approach is known as \textit{shrinkage methods} for linear models and is commonly referred to as \textit{weight decay} in neural networks.

\section{Probability Theory}

Probability theory provides a mathematical framework for representing and reasoning under uncertainty. In pattern recognition, uncertainty can arise from measurement noise, limited data, incomplete information, or intrinsic variability in the underlying process. By assigning probabilities to possible events or outcomes, probability theory makes it possible to quantify uncertainty and combine available information systematically. When combined with decision theory, it provides the basis for making predictions or decisions even when the available information is incomplete or ambiguous.

For discrete random variables, probabilities can be interpreted in terms of relative frequencies over repeated trials. If a random variable $X$ can take values $x_i$, then $p(X=x_i)$ denotes the probability that $X$ takes the value $x_i$. These probabilities satisfy

\begin{equation}
    0 \leq p(X=x_i) \leq 1,
\end{equation}

and, if the possible outcomes are mutually exclusive and exhaustive,

\begin{equation}
    \sum_i p(X=x_i) = 1.
\end{equation}

When two random variables $X$ and $Y$ are considered together, their joint probability $p(X,Y)$ describes the probability of particular combinations of their values. For discrete variables, $p(X=x_i,Y=y_j)$ denotes the probability that $X=x_i$ and $Y=y_j$ occur simultaneously. The probability distribution of one variable alone can be obtained by summing the joint distribution over all possible values of the other variable. This is called \textit{marginalization}, and gives the \textit{sum rule}

\begin{equation}
    p(X) = \sum_Y p(X,Y).
\end{equation}

The resulting $p(X)$ is called the \textit{marginal probability distribution} of $X$.

A \textit{conditional probability} describes the probability of one variable given that the value of another variable is known. The conditional probability of $Y$ given $X$ is written $p(Y \mid X)$. The joint and conditional distributions are related through the \textit{product rule}

\begin{equation}
    p(X,Y) = p(Y \mid X)p(X).
\label{eq:product_rule_1}
\end{equation}

Equivalently, by interchanging the roles of $X$ and $Y$,

\begin{equation}
    p(X,Y) = p(X \mid Y)p(Y).
\label{eq:product_rule_2}
\end{equation}

The sum rule and product rule form the basic algebra of probability and allow more complicated probability distributions to be constructed and manipulated.

Combining the two forms of the product rule gives \textit{Bayes' theorem}

\begin{equation}
    p(Y \mid X) = \frac{p(X \mid Y)p(Y)}{p(X)}.
\end{equation}

Using the sum rule, the denominator can be written as

\begin{equation}
    p(X) = \sum_Y p(X \mid Y)p(Y).
\end{equation}

Thus, Bayes' theorem can also be expressed as

\begin{equation}
    p(Y \mid X) = \frac{p(X \mid Y)p(Y)}{\sum_Y p(X \mid Y)p(Y)}.
\end{equation}

The denominator acts as a normalization factor ensuring that the posterior probabilities over all possible values of $Y$ sum to one.

Bayes' theorem provides a general mechanism for updating uncertainty when new information becomes available. The distribution $p(Y)$ represents knowledge about $Y$ before observing $X$ and is called the \textit{prior probability}. After observing $X$, the updated distribution $p(Y \mid X)$ is called the \textit{posterior probability}. The quantity $p(X \mid Y)$ describes how likely the observed data $X$ are under a particular value of $Y$ and is commonly called the \textit{likelihood}. Bayes' theorem therefore expresses the general relationship

\begin{equation}
    \mathrm{posterior}\,\propto\,\mathrm{likelihood}\times\mathrm{prior}.
\end{equation}

The posterior combines prior information with evidence supplied by the observed data.

Two random variables $X$ and $Y$ are said to be \textit{independent} if knowledge of one provides no information about the other. In this case, their joint probability factorizes as

\begin{equation}
    p(X,Y) = p(X)p(Y).
\end{equation}

Using the product rule in Eqs.~(\ref{eq:product_rule_1}) and~(\ref{eq:product_rule_2}), independence also implies

\begin{equation}
    p(Y \mid X) = p(Y),
\end{equation}

and similarly,

\begin{equation}
    p(X \mid Y) = p(X).
\end{equation}

Thus, for independent variables, conditioning on one variable does not alter the probability distribution of the other.

\section{Probability densities}

For a continuous random variable $x$, probabilities are described by a \textit{probability density function} $p(x)$ rather than by assigning probabilities directly to individual values. For an infinitesimal interval $(x,x+\delta x)$, the probability that the variable lies within that interval is approximately $p(x)\delta x$. More generally, the probability that $x$ lies in an interval $(a,b)$ is

\begin{equation}
    p(x \in (a,b)) = \int_a^b p(x)\,dx.
\end{equation}

A probability density must satisfy two fundamental conditions. First, it must be nonnegative everywhere,

\begin{equation}
    p(x) \geq 0,
\end{equation}

and second, it must be normalized so that the total probability over the entire domain is one,

\begin{equation}
    \int_{-\infty}^{\infty} p(x)\,dx = 1.
\end{equation}

Unlike probabilities themselves, the value of a probability density at a particular point is not a probability. For a continuous variable, the probability of observing exactly one particular value is zero; meaningful probabilities are obtained by integrating the density over intervals.

Under a change of variables, probability must be conserved. Suppose $x$ and $y$ are related by a differentiable, one-to-one transformation $x=g(y)$ ($g$ may be linear or nonlinear). For a small positive increment $\delta y>0$, the interval $(y,y+\delta y)$ corresponds to an interval $(x,x+\delta x)$, where

\begin{equation}
    \delta x = g(y+\delta y)-g(y).
\end{equation}

The length of the corresponding interval in $x$ is therefore $|\delta x|$. Since probability mass equals density times interval length, conservation of probability gives

\begin{equation}
    p_y(y)\,\delta y \approx p_x(x)\,|\delta x|.
\end{equation}

Dividing by $\delta y$ gives

\begin{equation}
    p_y(y) \approx p_x(x) \left|\frac{\delta x}{\delta y}\right|.
\end{equation}

Taking the limit as $\delta y \to 0$,

\begin{equation}
    p_y(y) = \lim_{\delta y \to 0} p_x(x) \left| \frac{\delta x}{\delta y} \right| = p_x(x) \left|\frac{dx}{dy}\right|.
\end{equation}

Since $x=g(y)$, this can be written as

\begin{equation}
    p_y(y) = p_x(g(y)) \left| g'(y) \right|.
\end{equation}

The factor $\left|dx/dy\right|$ is the \textit{Jacobian factor}. It accounts for the stretching or compression of intervals under the transformation. If the transformation stretches an interval, the density must decrease; if it compresses an interval, the density must increase, so that the total probability mass remains unchanged. Here, the role of the absolute value is evident, since a decreasing transformation gives $dx/dy<0$, whereas a probability density must remain nonnegative.

This also explains why a probability density is not itself a probability. The invariant quantity is the probability mass $p_x(x)\,dx$, not the numerical value of $p_x(x)$. Consequently, the shape and height of a density depend on the variable used to represent it. In particular, the location of the maximum of a density, or its \textit{mode}, is generally not preserved under a nonlinear transformation. If $\hat{x}$ is a mode of $p_x(x)$, so that

\begin{equation}
    \left.\frac{d p_x(x)}{dx}\right|_{x=\hat{x}} = 0,
\end{equation}

then the transformed density is $p_y(y)=p_x(g(y))|g'(y)|$. Its stationary points satisfy

\begin{equation}
    \frac{d}{dy}\left[p_x(g(y))|g'(y)|\right] = 0,
\end{equation}

which contains the Jacobian. For a nonlinear transformation $g$, the transformed mode is not the inverse transformation of the original mode, i.e., $\hat{y} \ne g^{-1}(\hat{x})$. For a linear transformation, however, $g'(y)$ is constant, so the Jacobian only rescales the density and does not change the corresponding location of its maximum.

So far, we have assumed that the transformation $g$ is one-to-one over the domain. If a transformation is not one-to-one, its domain must be partitioned into monotonic branches, and the probability contributions from all branches that map to the same transformed value must be added up. More generally, if $y=h(x)$ and the equation $y=h(x)$ has inverse solutions $x_i(y)$, then

\begin{equation}
    p_y(y) = \sum_i p_x\left(x_i(y)\right) \left| \frac{dx_i}{dy} \right|.
\end{equation}

For example, if $y=x^2$, then a positive value of $y$ can arise from both $x=\sqrt{y}$ and $x=-\sqrt{y}$, so both branches contribute to the density of $y$. This branch-summing rule is the general form of probability conservation for non-one-to-one transformations.

The \textit{cumulative distribution function} (CDF) gives the probability that a continuous random variable is less than or equal to a specified value. It is defined by

\begin{equation}
    P(z) = \int_{-\infty}^{z} p(x)\,dx.
\end{equation}

The probability density can be recovered from the cumulative distribution by differentiation,

\begin{equation}
    p(x) = \frac{dP(x)}{dx}.
\end{equation}

If we have several continuous variables $x_1,\ldots, x_D$, denoted collectively by the vector $\mathbf{x}$, then we can deﬁne a joint probability density $p(\mathbf{x}) = p(x_1,\ldots, x_D)$ such that the probability of $\mathbf{x}$ falling in an inﬁnitesimal volume $\delta \mathbf{x}$ containing the point $\mathbf{x}$ is given by $p(\mathbf{x})\delta x$. This multivariate probability density must satisfy

\begin{equation}
    p(\mathbf{x}) \geq 0
\end{equation}

and

\begin{equation}
    \int p(\mathbf{x})\,d\mathbf{x} = 1,
\end{equation}

where the integral is taken over the entire domain of $\mathbf{x}$.

The sum and product rules of probability extend naturally from discrete variables to continuous variables. For two continuous random variables $x$ and $y$, the marginal density of $x$ is obtained by integrating the joint density over all possible values of $y$,

\begin{equation}
    p(x) = \int p(x,y)\,dy.
\end{equation}

Thus, marginalization corresponds to summation for discrete variables and integration for continuous variables, while the product rule retains the same conceptual form. Bayes' theorem likewise applies to probability densities,

\begin{equation}
    p(y \mid x) = \frac{p(x \mid y)p(y)}{p(x)},
\end{equation}

with the denominator obtained by integrating over the possible values of $y$,

\begin{equation}
    p(x) = \int p(x \mid y)p(y)\,dy.
\end{equation}

Hence, the same basic probability rules apply to discrete distributions, continuous densities, and combinations of discrete and continuous random variables; the main difference is that summations over discrete states are replaced by integrations over continuous domains.

\section{Expectations and covariances}

The \textit{expectation} of a function $f(x)$ is its probability-weighted average under the distribution of $x$. For a discrete random variable,

\begin{equation}
    \mathbb{E}[f] = \sum_x p(x)f(x),
\end{equation}

whereas for a continuous random variable,

\begin{equation}
    \mathbb{E}[f] = \int p(x)f(x)\,dx.
\end{equation}

Thus, values of $f(x)$ that occur in regions of higher probability contribute more strongly to the average.

If $N$ independent samples $x_1,\ldots,x_N$ are drawn from the distribution of $x$, the expectation can be approximated by the empirical average

\begin{equation}
    \mathbb{E}[f] \approx \frac{1}{N}\sum_{n=1}^{N}f(x_n).
\end{equation}

As $N\to\infty$, this approximation converges to the true expectation under suitable conditions.

When a function depends on several random variables, a subscript can be used to indicate which variable is being averaged over. For example, $\mathbb{E}_x[f(x,y)]$ denotes expectation with respect to $x$, treating $y$ as fixed. The resulting quantity is therefore a function of $y$.

A \textit{conditional expectation} is an expectation taken with respect to a conditional distribution. For a discrete variable,

\begin{equation}
    \mathbb{E}_x[f \mid y] = \sum_x p(x \mid y)f(x).
\end{equation}

For a continuous variable,

\begin{equation}
    \mathbb{E}_x[f \mid y] = \int p(x \mid y)f(x)\,dx.
\end{equation}

This quantity represents the average value of $f(x)$ under the conditional distribution of $x$ given the observed value of $y$.

The \textit{variance} measures the average squared deviation of a random quantity from its mean. For a function $f(x)$,

\begin{equation}
    \operatorname{var}[f] = \mathbb{E}\left[\left(f(x)-\mathbb{E}[f(x)]\right)^2\right].
\end{equation}

Expanding the square gives the equivalent form

\begin{equation}
    \operatorname{var}[f] = \mathbb{E}[f(x)^2] - \mathbb{E}[f(x)]^2.
\end{equation}

In particular, for the random variable $x$ itself,

\begin{equation}
    \operatorname{var}[x] = \mathbb{E}[x^2] - \mathbb{E}[x]^2.
\end{equation}

Variance is always nonnegative and quantifies the spread of a random variable around its mean.

For two random variables $x$ and $y$ and functions $f(x)$ and $g(y)$, the \textit{covariance} measures the extent to which $f(x)$ and $g(y)$ vary together. It is defined as

\begin{equation}
    \operatorname{cov}[f(x),g(y)] = \mathbb{E}_{x,y} \left[\left(f(x)-\mathbb{E}[f(x)]\right) \left(g(y)-\mathbb{E}[g(y)]\right)\right].
\end{equation}

Expanding the product gives

\begin{equation}
    \operatorname{cov}[f(x),g(y)] = \mathbb{E}_{x,y}[f(x)g(y)] - \mathbb{E}[f(x)]\mathbb{E}[g(y)].
\end{equation}

A positive covariance indicates that $f(x)$ and $g(y)$ tend to deviate from their respective means in the same direction, whereas a negative covariance indicates that they tend to deviate in opposite directions.

As a particular case, taking $f(x)=x$ and $g(y)=y$ gives

\begin{equation}
    \operatorname{cov}[x,y] = \mathbb{E}_{x,y} \left[\left(x-\mathbb{E}[x]\right)\left(y-\mathbb{E}[y]\right)\right],
\end{equation}

or equivalently,

\begin{equation}
    \operatorname{cov}[x,y] = \mathbb{E}_{x,y}[xy] - \mathbb{E}[x]\,\mathbb{E}[y].
\end{equation}

If $x$ and $y$ are independent, then $f(x)$ and $g(y)$ are also independent, and therefore

\begin{equation}
\mathbb{E}_{x,y}[f(x)g(y)] = \mathbb{E}[f(x)]\mathbb{E}[g(y)],
\end{equation}

which implies

\begin{equation}
    \operatorname{cov}[f(x),g(y)] = 0.
\end{equation}

In particular, $\operatorname{cov}[x,y]=0$ when $x$ and $y$ are independent. However, zero covariance does not generally imply independence.

For random vectors $\mathbf{x}$ and $\mathbf{y}$, covariance generalizes to a matrix,

\begin{equation}
    \operatorname{cov}[\mathbf{x},\mathbf{y}] = \mathbb{E}_{\mathbf{x},\mathbf{y}}\left[\left(\mathbf{x}-\mathbb{E}[\mathbf{x}]\right)\left(\mathbf{y}-\mathbb{E}[\mathbf{y}]\right)^{\mathrm{T}}\right].
\end{equation}

Equivalently,

\begin{equation}
    \operatorname{cov}[\mathbf{x},\mathbf{y}] = \mathbb{E}[\mathbf{x}\mathbf{y}^{\mathrm{T}}] - \mathbb{E}[\mathbf{x}]\mathbb{E}[\mathbf{y}]^{\mathrm{T}}.
\end{equation}

If we consider the covariance of the components of a vector $\mathbf{x}$ with each other, then we use a slightly simpler notation $\operatorname{cov}[\mathbf{x}, \mathbf{x}] \equiv \operatorname{cov}[\mathbf{x}], \mathbf{x}]$.

\section{Bayesian probabilities}

The \textit{frequentist} interpretation of probability associates probability with the long-run frequency of outcomes in repeated experiments. This view is natural when the same random experiment can be repeated many times. The \textit{Bayesian} interpretation is more general and uses probability to represent uncertainty about quantities that may not be associated with repeatable events. In this view, probability expresses a degree of belief that can be updated when new evidence becomes available.

This distinction is particularly useful in pattern recognition, where uncertainty may concern not only the observed data but also unknown model parameters. Suppose a model is described by a parameter vector $\mathbf{w}$ and the observed data are denoted by $\mathcal{D}$. Before observing the data, uncertainty about $\mathbf{w}$ is represented by the \textit{prior distribution} $p(\mathbf{w})$, which may also be viewed as the generating distribution from which the model parameters are initialized. The likelihood $p(\mathcal{D}\mid\mathbf{w})$ assigns a score to each parameter value $\mathbf{w}$ according to how plausible the observed data $\mathcal{D}$ are under that choice of $\mathbf{w}$. After observing $\mathcal{D}$, the prior and likelihood are combined through Bayes' theorem to obtain the \textit{posterior distribution} $p(\mathbf{w}\mid\mathcal{D})$, which represents the updated uncertainty about the model parameters,

\begin{equation}
    p(\mathbf{w}\mid\mathcal{D}) = \frac{p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w})}{p(\mathcal{D})}.
\label{eq:c1_bayes_posterior}
\end{equation}

For example, consider the linear model

\begin{equation}
    y = wx + \epsilon,
\end{equation}

where

\begin{equation}
    \epsilon \sim \mathcal{N}(0,\sigma^2).
\end{equation}

For a given input $x_i$ and parameter $w$, the model implies

\begin{equation}
    p(y_i\mid x_i,w) = \mathcal{N}(y_i\mid wx_i,\sigma^2).
\end{equation}

For fixed $w$, this describes the distribution of possible observations $y_i$. Once an observation $y_i$ is obtained, the same expression can instead be viewed as a function of $w$, indicating how well each value of $w$ fits the observed data. Assuming data points are independent, then for the data set $\mathcal{D}=\{(x_i,y_i)\}_{i=1}^{N}$, the likelihood is

\begin{equation}
    p(\mathcal{D}\mid w) = \prod_{i=1}^{N} p(y_i\mid x_i,w).
\end{equation}

Each conditional density has the form

\begin{equation}
    p(y_i\mid x_i,w) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp \left[-\frac{(y_i-wx_i)^2}{2\sigma^2}\right].
\end{equation}

Substituting this Gaussian density into the likelihood gives

\begin{align}
    p(\mathcal{D}\mid w)
    &= \prod_{i=1}^{N} \frac{1}{\sqrt{2\pi\sigma^2}} \exp \left[-\frac{(y_i-wx_i)^2}{2\sigma^2}\right]
    \notag \\
    &= \left(\frac{1}{\sqrt{2\pi\sigma^2}}\right)^N \exp \left[-\frac{1}{2\sigma^2}\sum_{i=1}^{N}(y_i-wx_i)^2\right].
\label{eq:c1_likelihood_and_residual}
\end{align}

Hence, the likelihood assigned to $w$ depends directly on the total squared residual

\begin{equation}
    \sum_{i=1}^{N}(y_i-wx_i)^2.
\end{equation}

A value of $w$ that produces predictions $wx_i$ closer to the observations $y_i$ has a smaller total squared residual and therefore a larger likelihood. Conversely, a value of $w$ that produces larger residuals has a smaller likelihood. Thus, $p(\mathcal{D}\mid w)$ provides a quantitative score for how compatible each value of $w$ is with the observed data.

Because the likelihood is not a probability distribution over $\mathbf{w}$. Therefore, in general,

\begin{equation}
    \int p(\mathcal{D}\mid\mathbf{w})\,d\mathbf{w} \neq 1.
\end{equation}

Instead, for fixed $\mathbf{w}$, $p(\mathcal{D}\mid\mathbf{w})$ is a probability distribution over the possible data $\mathcal{D}$, and therefore

\begin{equation}
    \int p(\mathcal{D}\mid\mathbf{w})\,d\mathcal{D} = 1.
\end{equation}

Given this definition of likelihood, we can state Bayes' theorem in words

\begin{equation}
    \text{posterior} \propto \text{likelihood} \times \text{prior}.
\end{equation}

The denominator $p(\mathcal{D})$ in Eq.~\ref{eq:c1_bayes_posterior} is called the \textit{evidence} or \textit{marginal likelihood}. It is obtained by marginalizing the joint distribution $p(\mathcal{D},\mathbf{w})$ over the parameter space. Using the product rule,

\begin{equation}
    p(\mathcal{D},\mathbf{w}) = p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w}),
\end{equation}

and therefore

\begin{equation}
    p(\mathcal{D}) = \int p(\mathcal{D},\mathbf{w}) \, d\mathbf{w} = \int p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w}) \, d\mathbf{w}.
\end{equation}

Substituting this expression into Bayes' theorem gives

\begin{equation}
    p(\mathbf{w}\mid\mathcal{D}) = \frac{p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w})}{\int p(\mathcal{D}\mid\mathbf{w})p(\mathbf{w}) \, d\mathbf{w}}.
\label{eq:c1_bayes_normalization}
\end{equation}

The evidence therefore acts as the normalization constant for the product of the likelihood and prior, ensuring that the posterior distribution $p(\mathbf{w}\mid\mathcal{D})$ integrates to one.

The Bayesian and frequentist viewpoints therefore treat model parameters differently. In the frequentist approach, $\mathbf{w}$ is regarded as a fixed but unknown quantity, and uncertainty is characterized through the behavior of an estimator over multiple hypothetical data sets (one true $\mathbf{w}$, many possible $\mathcal{D}$). In the Bayesian approach, the observed data set is fixed, and uncertainty about $\mathbf{w}$ is represented directly by the posterior distribution $p(\mathbf{w}\mid\mathcal{D})$ (one true $\mathcal{D}$, many possible $\mathbf{w}$).

A widely used frequentist estimator is \textit{maximum likelihood}, in which $\mathbf{w}$ is set to the value that maximizes the likelihood function $p(\mathcal{D}\mid\mathbf{w})$. This corresponds to choosing the value of $\mathbf{w}$ for which the probability of the observed data set is maximized. Hence,

\begin{equation}
    \mathbf{w}_{\mathrm{ML}} = \arg\max_{\mathbf{w}} p(\mathcal{D}\mid\mathbf{w}).
\end{equation}

Because the logarithm is monotonically increasing, this is equivalent to maximizing the log-likelihood,

\begin{equation}
    \mathbf{w}_{\mathrm{ML}} = \arg\max_{\mathbf{w}} \log p(\mathcal{D}\mid\mathbf{w}),
\end{equation}

or minimizing the negative log-likelihood,

\begin{equation}
    \mathbf{w}_{\mathrm{ML}} = \arg\min_{\mathbf{w}} \left\{-\log p(\mathcal{D}\mid\mathbf{w})\right\}.
\end{equation}

In general, maximizing likelihood is equivalent to minimizing the discrepancy between predictions and observations. For a Gaussian model, Eq.~\ref{eq:c1_likelihood_and_residual} shows that it corresponds to minimizing the sum of squared residuals. This explains why the negative log-likelihood commonly appears as a loss function in machine learning.

In frequentist inference, one approach to estimating uncertainty in $\mathbf{w}$ is to examine how the estimator varies across possible data sets. One practical method is the \textit{bootstrap}. Given a data set $\mathcal{D}=\{(\mathbf{x}_i,y_i)\}^N_{i=1}$, a new data set is created by sampling $N$ points from $\mathcal{D}$ with replacement. Repeating this procedure $L$ times produces $L$ bootstrap data sets, and the variability of the corresponding parameter estimates can be used to assess statistical uncertainty.

One criticism of the Bayesian approach is that the prior distribution $p(\mathbf{w})$ may sometimes be chosen for mathematical or computational convenience rather than because it closely reflects genuine prior knowledge. Since the posterior depends directly on the prior through Eq.~\ref{eq:c1_bayes_normalization}, different reasonable choices of $p(\mathbf{w})$ can lead to different posterior distributions, especially when the available data are limited. This dependence introduces a degree of subjectivity into Bayesian inference. To reduce the influence of the prior, \textit{noninformative priors} are sometimes used. These priors are designed to place relatively little preference on particular parameter values before the data are observed, so that the likelihood has a stronger influence on the resulting posterior.

One criticism of the Bayesian approach is that the prior distribution $p(\mathbf{w})$ may be chosen for mathematical convenience rather than because it closely reflects genuine prior knowledge. Since the posterior depends on the prior by Eq.~\ref{eq:c1_bayes_normalization}, different choices of $p(\mathbf{w})$ can lead to different posterior distributions, which introduces a degree of subjectivity, especially when the available data are limited. \textit{Noninformative priors} are sometimes used to reduce this dependence by assigning relatively little preference to particular parameter values before the data is observed. Their goal is to let the likelihood dominate the posterior, with minimal influence from the prior.

That being said, constructing a truly noninformative prior is difficult because even a seemingly weak prior can still encode assumptions. For example, a Gaussian prior $p(w)=\mathcal{N}(0,\sigma^2)$ with a very large $\sigma^2$ may appear nearly flat over a wide range, but it still favors values near zero and assigns decreasing probability to increasingly large values of $|w|$. Similarly, a uniform prior is only uniform over a chosen range, so changing variables or changing the bounds can alter what is considered ``uninformative''. These choices become especially important in model comparison because Bayesian model evidence integrates the likelihood over the prior distribution, i.e., $p(\mathcal{D}) = \int p(\mathcal{D}\mid \mathbf{w})p(\mathbf{w})\,d\mathbf{w}$. As a result, the width and shape of the prior can substantially affect the marginal likelihood, so two models with similar fits to the data may receive different evidence values simply because their prior distributions allocate probability mass differently across parameter space. Moreover, a poorly chosen prior can lead to misleading posterior conclusions, especially when the available data are limited and the likelihood is not strong enough to overwhelm the prior. In such cases, the posterior may become highly concentrated around parameter values favored by the prior, giving the appearance of strong certainty even when that certainty is largely driven by an inappropriate prior assumption. Frequentist evaluation methods provide a useful external check because they assess predictive performance without relying on a prior specification. Techniques such as cross-validation are therefore valuable for detecting poor generalization and for comparing models based on their performance on held-out data.

The main practical difficulty of Bayesian inference is computational. Rather than selecting a single parameter value $\mathbf{w}$, Bayesian inference maintains a posterior distribution $p(\mathbf{w}\mid\mathcal{D})$ over plausible parameter values. Consequently, prediction requires accounting for uncertainty across the entire parameter space. For a new input $\mathbf{x}_*$, the posterior predictive distribution is obtained by marginalizing over $\mathbf{w}$. Starting from the law of total probability and applying the product rule,

\begin{equation}
\begin{aligned}
p(\mathbf{y}_*\mid\mathbf{x}_*,\mathcal{D})
&=
\int p(\mathbf{y}_*,\mathbf{w}\mid\mathbf{x}_*,\mathcal{D})\,d\mathbf{w} \\
&=
\int
p(\mathbf{y}_*\mid\mathbf{x}_*,\mathbf{w},\mathcal{D})p(\mathbf{w}\mid\mathbf{x}_*,\mathcal{D})\,d\mathbf{w}.
\end{aligned}
\label{eq:c1_bayes_inference}
\end{equation}

Given $\mathbf{w}$ and the new input $\mathbf{x}_*$, the prediction $\mathbf{y}_*$ is assumed to be conditionally independent of the training data $\mathcal{D}$, so

\begin{equation}
    p(\mathbf{y}_*\mid\mathbf{x}_*,\mathbf{w},\mathcal{D}) = p(\mathbf{y}_*\mid\mathbf{x}_*,\mathbf{w}).
\label{eq:c1_bayes_inference_a}
\end{equation}

In addition, treating $\mathbf{x}_*$ as a fixed new input means that it provides no additional information about $\mathbf{w}$ beyond the training data, so

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x}_*,\mathcal{D}) = p(\mathbf{w}\mid\mathcal{D}).
\label{eq:c1_bayes_inference_b}
\end{equation}

Substituting Eqs.~\ref{eq:c1_bayes_inference_a}--\ref{eq:c1_bayes_inference_b} into Eq.~\ref{eq:c1_bayes_inference}, we obtain

\begin{equation}
    p(\mathbf{y}_*\mid\mathbf{x}_*,\mathcal{D}) = \int p(\mathbf{y}_*\mid\mathbf{x}_*,\mathbf{w}) p(\mathbf{w}\mid\mathcal{D})\,d\mathbf{w}.
\end{equation}

Thus, Bayesian prediction does not rely on a single parameter estimate. Instead, it averages (or integrates) the predictive distribution associated with every possible $\mathbf{w}$, weighted by its posterior probability. When $\mathbf{w}$ is high-dimensional, this averaging requires integration over a correspondingly high-dimensional parameter space, which can make exact Bayesian prediction computationally expensive or intractable.

The development of sampling methods, such as Markov chain Monte Carlo (discussed in Chapter 11) along with dramatic improvements in the speed and memory capacity of computers, opened the door to the practical use of Bayesian techniques in an impressive range of problem domains. Monte Carlo methods are very ﬂexible and can be applied to a wide range of models. However, they are computationally intensive and have mainly been used for small-scale problems. More recently, highly efﬁcient deterministic approximation schemes such as variational Bayes and expectation propagation (discussed in Chapter 10) have been developed. These offer a complementary alternative to sampling methods and have allowed Bayesian techniques to be used in large-scale applications

\section{The Gaussian distribution}

Various proability distributions and their key properties will be discuss extensively in Chapter 2. This section is to introduce here the most important probability distribution for continuous variables, called the \textit{normal} or \textit{Gaussian} distribution.

For a scalar random variable $x$, the Gaussian density is defined by

\begin{equation}
    \mathcal{N}(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right].
\label{eq:c1_single_gaussian}
\end{equation}

which is governed by two parameters: $\mu$, called the \textit{mean}, and $\sigma^2$, called the variance. The square root of the variance, given by $\sigma$, is called the \textit{standard deviation}, and the reciprocal of the variance, written as $\beta = \frac{1}{\sigma^2}$, is called the \textit{precision}.

The Gaussian distribution satisfies the usual requirements for a continuous probability density,

\begin{equation}
    \mathcal{N}(x;\mu,\sigma^2) > 0
\end{equation}

and

\begin{equation}
    \int_{-\infty}^{\infty}\mathcal{N}(x;\mu,\sigma^2)\,dx = 1.
\end{equation}

We can readily ﬁnd expectations (its first moment) of functions of $x$ under the Gaussian distribution. In particular, the average value of x is given by

\begin{equation}
    \mathbb{E}[x] = \int_{-\infty}^{\infty}x\,\mathcal{N}(x; \mu,\sigma^2)\,dx = \mu,
\end{equation}

which is why $\mu$ is called the mean. Its second moment is

\begin{equation}
    \mathbb{E}[x^2] = \int_{-\infty}^{\infty}x^2\,\mathcal{N}(x;\mu,\sigma^2)\,dx = \mu^2+\sigma^2.
\end{equation}

Using the change of variable $z=x-\mu$, so that $x=z+\mu$ and $dx=dz$, we obtain

\begin{equation}
\begin{aligned}
    \mathbb{E}[x] &= \int_{-\infty}^{\infty} (z+\mu)\,\mathcal{N}(z;0,\sigma^2)\,dz \\
    &=
    \int_{-\infty}^{\infty} z\,\mathcal{N}(z;0,\sigma^2)\,dz + \mu \int_{-\infty}^{\infty}\mathcal{N}(z;0,\sigma^2)\,dz.
\end{aligned}
\end{equation}

Because $\mathcal{N}(z;0,\sigma^2)$ is symmetric about zero, $z\,\mathcal{N}(z;0,\sigma^2)$ is an odd function, and therefore

\begin{equation}
    \int_{-\infty}^{\infty} z\,\mathcal{N}(z;0,\sigma^2)\,dz = 0.
\end{equation}

Also, any density function should integrate to one, therefore

\begin{equation}
    \int_{-\infty}^{\infty}\mathcal{N}(z;0,\sigma^2)\,dz = 1.
\end{equation}

It follows that

\begin{equation}
    \mathbb{E}[x] = 0 + \mu = \mu,
\end{equation}

which is why $\mu$ is called the mean. Similarly, its second moment is

\begin{equation}
    \mathbb{E}[x^2] = \int_{-\infty}^{\infty} x^2\,\mathcal{N}(x\mid\mu,\sigma^2)\,dx.
\end{equation}

Keep using the change of variable $z=x-\mu$, we obtain

\begin{equation}
\begin{aligned}
    \mathbb{E}[x^2]
    &=
    \int_{-\infty}^{\infty}(z+\mu)^2\,\mathcal{N}(z;0,\sigma^2)\,dz \\
    &=
    \int_{-\infty}^{\infty}\left(z^2+2\mu z+\mu^2\right)\mathcal{N}(z;0,\sigma^2)\,dz \\
    &=
    \int_{-\infty}^{\infty}z^2\,\mathcal{N}(z;0,\sigma^2)\,dz
    + 2\mu \int_{-\infty}^{\infty}z\,\mathcal{N}(z;0,\sigma^2)\,dz \\
    &\qquad
    + \mu^2 \int_{-\infty}^{\infty}\mathcal{N}(z;0,\sigma^2)\,dz.
\end{aligned}
\end{equation}

As shown above,

\begin{equation}
    \int_{-\infty}^{\infty}z\,\mathcal{N}(z;0,\sigma^2)\,dz = 0
\end{equation}

and

\begin{equation}
    \int_{-\infty}^{\infty}\mathcal{N}(z;0,\sigma^2)\,dz = 1.
\end{equation}

For the remaining term, using

\begin{equation}
    \mathcal{N}(z;0,\sigma^2) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{z^2}{2\sigma^2}\right),
\end{equation}

we have

\begin{equation}
    \int_{-\infty}^{\infty}
    z^2\,\mathcal{N}(z;0,\sigma^2)\,dz
    =
    \frac{1}{\sqrt{2\pi}\sigma}
    \int_{-\infty}^{\infty}
    z^2
    \exp\left(-\frac{z^2}{2\sigma^2}\right)\,dz.
\end{equation}

Since

\begin{equation}
    \frac{d}{dz}\exp\left(-\frac{z^2}{2\sigma^2}\right) = -\frac{z}{\sigma^2}\exp\left(-\frac{z^2}{2\sigma^2}\right),
\end{equation}

we can write

\begin{equation}
    z^2 \exp\left(-\frac{z^2}{2\sigma^2}\right) = -\sigma^2 z \frac{d}{dz}\exp\left(-\frac{z^2}{2\sigma^2}\right).
\end{equation}

Applying integration by parts gives

\begin{equation}
\begin{aligned}
    \int_{-\infty}^{\infty}
    z^2
    \exp\left(-\frac{z^2}{2\sigma^2}\right)\,dz
    &=
    -\sigma^2
    \left[
    z\exp\left(-\frac{z^2}{2\sigma^2}\right)
    \right]_{-\infty}^{\infty} \\
    &\qquad
    +
    \sigma^2
    \int_{-\infty}^{\infty}
    \exp\left(-\frac{z^2}{2\sigma^2}\right)\,dz.
\end{aligned}
\end{equation}

The boundary term is

\begin{equation}
    \left[z\exp\left(-\frac{z^2}{2\sigma^2}\right)\right]_{-\infty}^{\infty}
    =
    \lim_{z\to\infty} \frac{z}{\exp\left(\frac{z^2}{2\sigma^2}\right)}
    -
    \lim_{z\to-\infty} \frac{z}{\exp\left(\frac{z^2}{2\sigma^2}\right)}.
\end{equation}

Applying L'Hôpital's rule gives

\begin{equation}
    \lim_{z\to\pm\infty}\frac{z}{\exp\left(\frac{z^2}{2\sigma^2}\right)}
    =
    \lim_{z\to\pm\infty}\frac{1}{\frac{z}{\sigma^2}\exp\left(\frac{z^2}{2\sigma^2}\right)}
    = 0.
\end{equation}

Therefore,

\begin{equation}
    \left[z\exp\left(-\frac{z^2}{2\sigma^2}\right)\right]_{-\infty}^{\infty} = 0.
\end{equation}

Thus, the boundary term vanishes. Consequently,

\begin{equation}
    \int_{-\infty}^{\infty}z^2\,\mathcal{N}(z;0,\sigma^2)\,dz = \sigma^2\int_{-\infty}^{\infty}\mathcal{N}(z;0,\sigma^2)\,dz = \sigma^2.
\end{equation}

It follows that

\begin{equation}
    \mathbb{E}[x^2] = \sigma^2 + 2\mu(0) + \mu^2(1) = \mu^2+\sigma^2.
\end{equation}

Using $\operatorname{var}[x]=\mathbb{E}[x^2]-\mathbb{E}[x]^2$, we obtain

\begin{equation}
    \operatorname{var}[x] = \sigma^2,
\end{equation}

which is why $\sigma^2$ is called the variance. The Gaussian is symmetric about $\mu$, and its mode coincides with its mean,

\begin{equation}
    x_{\mathrm{mode}} = \mu.
\end{equation}

For a $D$-dimensional random vector $\mathbf{x}$, the corresponding multivariate Gaussian distribution is

\begin{equation}
    \mathcal{N}(\mathbf{x};\,\boldsymbol{\mu},\boldsymbol{\Sigma})
    =
    \frac{1}{(2\pi)^{D/2}|\boldsymbol{\Sigma}|^{1/2}}\exp\left[-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right],
\label{eq:c1_multivariate_gaussian}
\end{equation}

where $\boldsymbol{\mu}\in\mathbb{R}^{D}$ is the mean vector, $\boldsymbol{\Sigma}\in\mathbb{R}^{D\times D}$ is the covariance matrix, and $|\boldsymbol{\Sigma}|$ is the determinant of $\Sigma$. The properties of multivariate Gaussian distribution will be studied in Chapter 2.

Now suppose we observe a data set $\mathbf{x}=(x_1,\ldots,x_N)^{\mathrm{T}}$ consisting of $N$ scalar observations drawn independently from the same Gaussian distribution with unknown parameters $\mu$ and $\sigma^2$. The observations are therefore assumed to be \textit{independent and identically distributed} (i.i.d.),

\begin{equation}
    x_n \overset{\mathrm{i.i.d.}}{\sim}\mathcal{N}(\mu,\sigma^2).
\end{equation}

Independence allows the joint probability of the data set to factorize,

\begin{equation}
    p(\mathbf{x};\,\mu,\sigma^2) = \prod_{n=1}^{N}\mathcal{N}(x_n;\,\mu,\sigma^2).
\end{equation}

When the observed data $\mathbf{x}$ are held fixed and this expression is viewed as a function of $\mu$ and $\sigma^2$, it becomes the \textit{likelihood function} for the Gaussian parameters. Instead of finding the parameter values that directly maximize the likelihood function, it is usually more convenient to maximize its logarithm. Taking the logarithm converts the product over observations into a sum,

\begin{align}
    \ln p(\mathbf{x}\mid\mu,\sigma^2)
    &=
    \sum_{n=1}^{N}\ln \mathcal{N}(x_n\mid\mu,\sigma^2) \\
    &=
    -\frac{1}{2\sigma^2}\sum_{n=1}^{N}(x_n-\mu)^2-\frac{N}{2}\ln\sigma^2-\frac{N}{2}\ln(2\pi).
\end{align}

The log-likelihood is also numerically more stable because multiplying many small probabilities can lead to numerical underflow, whereas taking logarithms replaces products by sums. The maximum likelihood estimate of the mean is obtained by differentiating the log-likelihood with respect to $\mu$ and setting the result to zero,

\begin{equation}
    \frac{\partial}{\partial\mu} \ln p(\mathbf{x}\mid\mu,\sigma^2) = \frac{1}{\sigma^2}\sum_{n=1}^{N}(x_n-\mu) = 0.
\end{equation}

Solving for $\mu$ gives

\begin{equation}
    \mu_{\mathrm{ML}} = \frac{1}{N}\sum_{n=1}^{N}x_n,
\label{eq:c1_gaussian_mean_estimate}
\end{equation}

which is simply the sample mean.

Differentiating with respect to $\sigma^2$ gives

\begin{align}
    \frac{\partial}{\partial \sigma^2} \ln p(\mathbf{x};\mu,\sigma^2)
    &=
    \frac{1}{2\sigma^4} \sum_{n=1}^{N}(x_n-\mu)^2 - \frac{N}{2\sigma^2}.
\end{align}

Setting the derivative equal to zero and multiply both sides by $2\sigma^4$ gives

\begin{equation}
    \sum_{n=1}^{N}(x_n-\mu)^2 - N\sigma^2 = 0.
\end{equation}

Evaluating this expression at the maximum likelihood estimate $\mu=\mu_{\mathrm{ML}}$ yields

\begin{equation}
    \sigma_{\mathrm{ML}}^2 = \frac{1}{N}\sum_{n=1}^{N}(x_n-\mu_{\mathrm{ML}})^2.
\label{eq:c1_gaussian_variance_estimate}
\end{equation}

From Eq.~\ref{eq:c1_gaussian_mean_estimate} and Eq.~\ref{eq:c1_gaussian_variance_estimate}, it follows that, for Gaussian observations, maximum likelihood estimation produces the sample mean and the sample variance (measured relative to the sample mean).

An important issue is that an estimator is itself a random variable because its value depends on the random data set from which it is computed. If repeated data sets are drawn independently from the same distribution,
then $\mu_{\mathrm{ML}}$ and $\sigma_{\mathrm{ML}}^2$ will generally take different values for different data sets. We can therefore study their expectations over all possible data sets.

For the maximum likelihood estimate of the mean $\mu_\mathrm{ML}$ from Eq.~\ref{eq:c1_gaussian_mean_estimate}, we take the expectation and using the linearity of expectation,

\begin{equation}
    \mathbb{E}[\mu_{\mathrm{ML}}]
    = \mathbb{E}\left[\frac{1}{N}\sum_{n=1}^{N}x_n\right]
    = \frac{1}{N}\sum_{n=1}^{N}\mathbb{E}[x_n]
    = \frac{1}{N}\sum_{n=1}^{N}\mu = \mu,
\label{eq:c1_maximum_likelihood_mean}
\end{equation}

so $\mu_{\mathrm{ML}}$ is an unbiased estimator of the true mean.

To derive the expectation of the variance estimator from Eq.~\ref{eq:c1_gaussian_variance_estimate}, we first observe that

\begin{equation}
\begin{aligned}
    \sigma_{\mathrm{ML}}^2 &= \frac{1}{N}\sum_{n=1}^{N} (x_n-\mu_{\mathrm{ML}})^2
    = \frac{1}{N}\sum_{n=1}^{N}\left[(x_n-\mu) - (\mu_{\mathrm{ML}}-\mu)\right]^2 \\
    &= \frac{1}{N}\sum_{n=1}^{N}(x_n-\mu)^2 - \frac{2}{N}(\mu_{\mathrm{ML}}-\mu)\sum_{n=1}^{N}(x_n-\mu) + (\mu_{\mathrm{ML}}-\mu)^2.
\end{aligned}
\end{equation}

Since

\begin{equation}
    \sum_{n=1}^{N}(x_n-\mu) = N(\mu_{\mathrm{ML}}-\mu),
\end{equation}

we obtain

\begin{equation}
    \sigma_{\mathrm{ML}}^2 = \frac{1}{N} \sum_{n=1}^{N}(x_n-\mu)^2 - (\mu_{\mathrm{ML}}-\mu)^2.
\end{equation}

Taking the expectation of both sides,

\begin{equation}
    \mathbb{E}\left[\sigma_{\mathrm{ML}}^2\right] = \frac{1}{N} \sum_{n=1}^{N}\mathbb{E}\left[(x_n-\mu)^2\right] - \mathbb{E}\left[(\mu_{\mathrm{ML}}-\mu)^2\right].
\end{equation}

Because each $x_n$ has variance $\sigma^2$, we have $\mathbb{E}\left[(x_n-\mu)^2\right] = \sigma^2$. Also, because we already know that $\mu_{\mathrm{ML}}$ is unbiased, i.e., $\mathbb{E}\left[\mu_\mathrm{ML}\right] = \mu$, and the data points are assumed to be independent, i.e., $\operatorname{cov}(x_i,x_j), \forall i \neq i$, we obtain

\begin{equation}
\begin{aligned}
    \mathbb{E} \left[(\mu_{\mathrm{ML}}-\mu)^2\right] &= \operatorname{var}[\mu_{\mathrm{ML}}] =
    \operatorname{var}\left[\frac{1}{N}\sum_{n=1}^{N}x_n\right] \\
    &=
    \frac{1}{N^2}\sum_{n=1}^{N}\operatorname{var}[x_n] = \frac{1}{N^2} N\sigma^2 = \frac{\sigma^2}{N}.
\end{aligned}
\end{equation}

Therefore,

\begin{equation}
    \mathbb{E}\left[\sigma_{\mathrm{ML}}^2\right]
    = \sigma^2 - \frac{\sigma^2}{N} \\
    = \frac{(N-1)}{N}\sigma^2.
\label{eq:c1_maximum_likelihood_variance}
\end{equation}

Thus, the maximum likelihood variance estimator systematically underestimates the true variance by a factor of $(N-1)/N$.

It follows from Eq.~\ref{eq:c1_maximum_likelihood_variance} that the following estimate for the variance parameter is unbiased

\begin{equation}
    \widetilde{\sigma}^2 = \frac{N}{N-1}\sigma_{\mathrm{ML}}^2 = \frac{1}{N-1}\sum_{n=1}^{N}(x_n-\mu_{\mathrm{ML}})^2.
\end{equation}

In chapter 10, we shall see how this result arises automatically when we adopt a Bayesian approach.

Note that the bias of the maximum likelihood solution becomes less signiﬁcant as the number N of data points increases, and in the limit $N\to\infty$ the maximum likelihood solution for the variance equals the true variance of the distribution that generated the data. In practice, for anything other than small N , this bias will not prove to be a serious problem. However, in more complex models with many parameters, the bias problems associated with maximum likelihood will be much more severe.

\section{Maximum likelihood and maximum a posterior (MAP): a polynomial regression example}

A polynomial curve-fitting problem can be formulated probabilistically by treating the target value $t$ as a random variable whose distribution depends on the input $x$ and the polynomial parameters $\mathbf{w}$. Let

\begin{equation}
    y(x,\mathbf{w}) = \sum_{j=0}^{M} w_j x^j
\end{equation}

denote the polynomial prediction. We assume that, for a given $x$, the observed target $t$ is generated from a Gaussian distribution centered at $y(x,\mathbf{w})$,

\begin{equation}
    p(t\mid x,\mathbf{w},\beta) = \mathcal{N}\left(t;y(x,\mathbf{w}),\beta^{-1}\right),
\end{equation}

where $\beta$ is the precision (inverse of variance) of the observation noise. Equivalently, this model can be written as

\begin{equation}
    t = y(x,\mathbf{w}) + \epsilon,
\end{equation}

with

\begin{equation}
    \epsilon \sim \mathcal{N}(0;\beta^{-1}).
\end{equation}

Thus, the polynomial determines the conditional mean of the target, and $\beta$ controls the prediction uncertainty.

Consider a training set

\begin{equation}
    \mathcal{D} = \left\{(x_n,t_n)\right\}_{n=1}^{N}.
\end{equation}

Assuming that the target observations are conditionally independent given the inputs and model parameters, the likelihood of the complete target vector $\mathbf{t}=(t_1,\ldots,t_N)^{\mathrm{T}}$ factorizes as

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) = \prod_{n=1}^{N} p(t_n\mid x_n,\mathbf{w},\beta)
    = \prod_{n=1}^{N}\mathcal{N}\left(t_n;y(x_n,\mathbf{w}),\beta^{-1}\right).
\end{equation}

However

\begin{equation}
\begin{aligned}
    \mathcal{N}
    \left(t_n;y(x_n,\mathbf{w}),\beta^{-1}\right)
    &=
    \frac{1}{\sqrt{2\pi\beta^{-1}}}\exp\left[-\frac{\left(t_n-y(x_n,\mathbf{w})\right)^2}{2\beta^{-1}}\right] \\
    &=
    \left(\frac{\beta}{2\pi}\right)^{1/2}\exp\left[-\frac{\beta}{2}\left(t_n-y(x_n,\mathbf{w})\right)^2\right].
\end{aligned}
\end{equation}

Hence,

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) = \left(\frac{\beta}{2\pi}\right)^{N/2}\exp\left[-\frac{\beta}{2}\sum_{n=1}^{N}\left(t_n-y(x_n,\mathbf{w})\right)^2\right].
\label{eq:c1_gaussian_likelihood}
\end{equation}

We now take the logarithm

\begin{equation}
    \ln p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) = -\frac{\beta}{2}\sum_{n=1}^{N}\left(y(x_n,\mathbf{w})-t_n\right)^2 + \frac{N}{2}\ln\beta - \frac{N}{2}\ln(2\pi).
\label{eq:c1_gaussian_log_likelihood}
\end{equation}

To estimate $\mathbf{w}$ by maximum likelihood, $\beta$ can be regarded as fixed. Because the last two terms do not depend on $\mathbf{w}$, and the factor $\beta$ does not change the location of the optimum, the maximum likelihood problem

\begin{equation}
    \mathbf{w}_{\mathrm{ML}} = \arg\max_{\mathbf{w}}p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta),
\end{equation}

is equivalent to

\begin{equation}
    \mathbf{w}_{\mathrm{ML}} = \arg\min_{\mathbf{w}}\frac{1}{2}\sum_{n=1}^{N}\left(y(x_n,\mathbf{w})-t_n\right)^2.
\end{equation}

Hence, the familiar sum-of-squares error function arises directly from maximum likelihood estimation under the assumption of Gaussian observation noise. This illustrates the more general connection between probabilistic modeling and loss functions: the assumed observation distribution determines the form of the corresponding negative log-likelihood.

The precision parameter $\beta$ can also be estimated by maximum likelihood. Differentiating the log-likelihood with respect to $\beta$ gives

\begin{equation}
    \frac{\partial}{\partial\beta}\ln p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) = -\frac{1}{2}\sum_{n=1}^{N}\left(y(x_n,\mathbf{w})-t_n\right)^2 + \frac{N}{2\beta}.
\end{equation}

Setting this derivative equal to zero and evaluating at $\mathbf{w}=\mathbf{w}_{\mathrm{ML}}$ gives

\begin{equation}
    \frac{1}{\beta_{\mathrm{ML}}} = \frac{1}{N}\sum_{n=1}^{N}\left(y(x_n,\mathbf{w}_{\mathrm{ML}}) - t_n\right)^2.
\end{equation}

Thus, the maximum likelihood estimate of the uncertainty is the mean squared residual of the fitted model.

Once $\mathbf{w}_{\mathrm{ML}}$ and $\beta_{\mathrm{ML}}$ have been estimated, prediction for a new input $x$ is no longer represented only by the point estimate $y(x,\mathbf{w}_{\mathrm{ML}})$. Instead, the probabilistic model provides the predictive distribution

\begin{equation}
    p(t\mid x,\mathbf{w}_{\mathrm{ML}},\beta_{\mathrm{ML}}) = \mathcal{N}\left(t;y(x,\mathbf{w}_{\mathrm{ML}}),\beta_{\mathrm{ML}}^{-1}\right).
\end{equation}

Its mean gives the usual polynomial prediction, and its variance represents uncertainty arising from the assumed observation noise. At this stage, however, maximum likelihood remains a frequentist method, so the parameters themselves are still represented by point estimates rather than by probability distributions.

A Bayesian treatment introduces a prior distribution over the polynomial coefficients. A common choice is an isotropic zero-mean Gaussian prior,

\begin{equation}
    p(\mathbf{w}\mid\alpha) = \mathcal{N}\left(\mathbf{w};\mathbf{0},\alpha^{-1}\mathbf{I}\right),
\end{equation}

where $\alpha$ is the prior precision. For an $M$th-order polynomial, the parameter vector $\mathbf{w}$ contains $M+1$ coefficients, so in the multivariate Gaussian distribution given in Eq.~\ref{eq:c1_multivariate_gaussian} we have $D=M+1$, $\boldsymbol{\mu}=\mathbf{0}$, and $\boldsymbol{\Sigma}=\alpha^{-1}\mathbf{I}$. Also, because $\boldsymbol{\Sigma}$ is an $(M+1)\times(M+1)$ diagonal matrix with every diagonal entry equal to $\alpha^{-1}$, its determinant is

\begin{equation}
    \left|\boldsymbol{\Sigma}\right| = \left|\alpha^{-1}\mathbf{I}\right| = \alpha^{-(M+1)},
\end{equation}

and therefore

\begin{equation}
    |\boldsymbol{\Sigma}|^{1/2} = \alpha^{-(M+1)/2}.
\end{equation}

Its inverse is

\begin{equation}
    \boldsymbol{\Sigma}^{-1} = (\alpha^{-1}\mathbf{I})^{-1} = \alpha\mathbf{I}.
\end{equation}

Substituting these expressions into Eq.~\ref{eq:c1_multivariate_gaussian} gives

\begin{equation}
\begin{aligned}
    p(\mathbf{w}\mid\alpha)
    &= \frac{1}{(2\pi)^{D/2}|\boldsymbol{\Sigma}|^{1/2}}\exp\left[-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^{\mathrm{T}}\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right]\\
    &=
    \frac{1}{(2\pi)^{(M+1)/2}\alpha^{-(M+1)/2}}\exp\left(-\frac{1}{2}\mathbf{w}^{\mathrm{T}}(\alpha\mathbf{I})\mathbf{w}\right) \\
    &=
    \left(\frac{\alpha}{2\pi}\right)^{(M+1)/2}\exp\left(-\frac{\alpha}{2}\mathbf{w}^{\mathrm{T}}\mathbf{w}\right).
\end{aligned}
\label{eq:c1_gaussian_prior}
\end{equation}

As $p(\mathbf{w}\mid\alpha)\uparrow\downarrow\mathbf{w}^{\mathrm{T}}\mathbf{w}$, the prior $p(\mathbf{w}\mid\alpha)$ favors parameter vectors with smaller Euclidean norm and assigns progressively lower probability to vectors containing large coefficients. The quantities $\alpha$ and $\beta$, which control the prior and observation distributions, are examples of \textit{hyperparameters}.

Using Bayes' theorem, the posterior distribution over $\mathbf{w}$ is

\begin{equation}
    p(\mathbf{w}\mid\mathbf{t},\mathbf{x},\alpha,\beta) = \frac{p(\mathbf{t}\mid\mathbf{w},\mathbf{x},\alpha,\beta)p(\mathbf{w}\mid\mathbf{x},\alpha,\beta)}{p(\mathbf{t}\mid\mathbf{x},\alpha,\beta)}.
\end{equation}

Because the prior over $\mathbf{w}$ depends only on $\alpha$,

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\alpha,\beta) = p(\mathbf{w}\mid\alpha),
\end{equation}

and because the likelihood depends on $\beta$ and $\mathbf{w}$ but not directly on $\alpha$,

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\alpha,\beta) = p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta),
\end{equation}

and because the denominator is the evidence, obtained by marginalizing over all possible values of $\mathbf{w}$,

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\alpha,\beta) = \int p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)p(\mathbf{w}\mid\alpha)\,d\mathbf{w}.
\end{equation}

Therefore,

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta) = \frac{p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)p(\mathbf{w}\mid\alpha)}{\int p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)p(\mathbf{w}\mid\alpha)\,d\mathbf{w}}.
\end{equation}

For determining the value of $\mathbf{w}$ that maximizes the posterior, the evidence in the denominator can be ignored because it does not depend on $\mathbf{w}$. Therefore,

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta)\propto p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)p(\mathbf{w}\mid\alpha).
\label{eq:c1_posterior_proportional}
\end{equation}

The \textit{maximum a posteriori (MAP)} estimate is then

\begin{equation}
\begin{aligned}
    \mathbf{w}_{\mathrm{MAP}}
    &= \arg\max_{\mathbf{w}}p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta) \\
    &= \arg\max_{\mathbf{w}}\left[p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)p(\mathbf{w}\mid\alpha)\right].
\end{aligned}
\end{equation}

Taking the negative logarithm,

\begin{equation}
    \mathbf{w}_{\mathrm{MAP}} = \arg\min_{\mathbf{w}}\left[-\ln p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) -\ln p(\mathbf{w}\mid\alpha)\right].
\end{equation}

Combining with Eq.~\ref{eq:c1_gaussian_log_likelihood} and Eq.~\ref{eq:c1_gaussian_prior}

\begin{equation}
\begin{aligned}
\mathbf{w}_{\mathrm{MAP}}
= \arg\min_{\mathbf{w}}
\Bigg[
&\frac{\beta}{2}\sum_{n=1}^{N}\left(y(x_n,\mathbf{w})-t_n\right)^2 - \frac{N}{2}\ln\beta + \frac{N}{2}\ln(2\pi) \\
&+ \frac{\alpha}{2}\mathbf{w}^{\mathrm{T}}\mathbf{w} - \frac{M+1}{2}\ln\alpha + \frac{M+1}{2}\ln(2\pi)
\Bigg].
\end{aligned}
\end{equation}

Discarding terms that do not depend on $\mathbf{w}$ and dividing the objective by a positive constant $\beta/2$ do not change the optimum. Therefore, the MAP estimate is equivalently given by

\begin{equation}
    \mathbf{w}_{\mathrm{MAP}} = \arg\min_{\mathbf{w}}\left[\sum_{n=1}^{N}\left(y(x_n,\mathbf{w})-t_n\right)^2 + \lambda\mathbf{w}^{\mathrm{T}}\mathbf{w}\right].
\end{equation}

where $\lambda=\alpha/\beta$. Thus, maximizing the posterior distribution is equivalent to minimizing a sum-of-squares error with an $L_2$ regularization term, commonly known as \textit{ridge regularization}.

This result is not specific to polynomial curve fitting. More generally, whenever the observation errors are assumed to be independent Gaussian with common variance $\beta^{-1}$ and the model parameters are assigned a zero-mean Gaussian prior with variance $\alpha^{-1}$, MAP estimation leads to an objective consisting of a squared-error term together with an $L_2$ regularization term, with regularization coefficient $\lambda=\beta^{-1}/\alpha^{-1}$. The Gaussian observation model produces the squared-error term through its negative log-likelihood, and the Gaussian parameter prior produces the $L_2$ penalty.

Although MAP is a Bayesian approach because it introduces a prior distribution $p(\mathbf{w}\mid\alpha)$ for the parameters, it still reduces the uncertainty in $\mathbf{w}$ to a single point estimate $\mathbf{w}_{\mathrm{MAP}}$. The next section introduces a full Bayesian approach.

\section{Bayesian curve fitting}

A fully Bayesian treatment differs from maximum likelihood or MAP estimation in that the entire posterior distribution $p(\mathbf{w}\mid\mathbf{x},\mathbf{t})$ is retained and marginalized when making predictions. In the curve-fitting problem, given training inputs $\mathbf{x}=(x_1,\ldots,x_N)^{\mathrm{T}}$, corresponding targets $\mathbf{t}=(t_1,\ldots,t_N)^{\mathrm{T}}$, and a new input $x$, the goal is to determine the predictive distribution of the corresponding target $t$.

Instead of predicting with a single parameter vector such as $\mathbf{w}_{\mathrm{ML}}$ or $\mathbf{w}_{\mathrm{MAP}}$, the predictive distribution is obtained by averaging the predictions associated with all possible parameter values, weighted by their posterior probability.

\begin{equation}
    p(t\mid x,\mathbf{x},\mathbf{t}) = \int p(t\mid x,\mathbf{w}) p(\mathbf{w}\mid\mathbf{x},\mathbf{t})\,d\mathbf{w}.
\label{eq:c1_bayesian_predictive_distribution}
\end{equation}

For polynomial curve fitting, it is convenient to write the model using the feature vector $\boldsymbol{\phi}(x)$ with elements $\phi_i(x) = x^i$ for $i=0,\dots,M$. The Gaussian model now becomes

\begin{equation}
    p(t\mid x,\mathbf{w},\beta) = \mathcal{N}\left(t;\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x),\beta^{-1}\right),
\label{eq:c1_polynomial_bayesian_model}
\end{equation}

For fixed training data $\mathbf{x}$ and $\mathbf{t}$, the model in Eq.~\ref{eq:c1_polynomial_bayesian_model} is viewed as a function of $\mathbf{w}$ and $\beta$, giving the likelihood.

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta) = \prod_{n=1}^{N}\mathcal{N}\left(t_n;\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n),\beta^{-1}\right).
\end{equation}

The Gaussian prior is

\begin{equation}
    p(\mathbf{w}\mid\alpha) = \mathcal{N}\left(\mathbf{w};\mathbf{0},\alpha^{-1}\mathbf{I}\right).
\end{equation}

Similar to Eq.~\ref{eq:c1_gaussian_likelihood} and Eq.~\ref{eq:c1_gaussian_prior}, the likelihood and the prior can be written, up to factors independent of $\mathbf{w}$, as

\begin{equation}
    p(\mathbf{t}\mid\mathbf{x},\mathbf{w},\beta)\propto\exp\left[-\frac{\beta}{2}\sum_{n=1}^{N}\left(t_n-\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n)\right)^2\right]
\end{equation}

and

\begin{equation}
    p(\mathbf{w}\mid\alpha)\propto\exp\left(-\frac{\alpha}{2}\mathbf{w}^{\mathrm{T}}\mathbf{w}\right).
\end{equation}

The posterior is proportional to the product of the likelihood and the prior (Eq.~\ref{eq:c1_posterior_proportional}), therefore

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta)\propto\exp\left[-\frac{1}{2}\left\{\beta\sum_{n=1}^{N}\left(t_n-\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n)\right)^2 + \alpha\mathbf{w}^{\mathrm{T}}\mathbf{w}\right\}\right].
\end{equation}

Expand the squared residual,

\begin{equation}
    \left(t_n-\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n)\right)^2 = t_n^2 - 2t_n\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n) + \mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n)\boldsymbol{\phi}(x_n)^{\mathrm{T}}\mathbf{w}.
\end{equation}

Summing over all observations and multiplyig with $\beta$ give

\begin{equation}
\begin{aligned}
    \beta\sum_{n=1}^{N}\left(t_n-\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x_n)\right)^2
    &=
    \beta\sum_{n=1}^{N}t_n^2 -2\beta\mathbf{w}^{\mathrm{T}}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n \\
    &\quad+
    \beta\mathbf{w}^{\mathrm{T}}\left[\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)\boldsymbol{\phi}(x_n)^{\mathrm{T}}\right]\mathbf{w}.
\end{aligned}
\end{equation}

Substituting this expansion into the posterior exponent and dropping the term $\beta\sum_{n=1}^{N}t_n^2$ that does not depend on $\mathbf{w}$ gives

\begin{equation}
\begin{aligned}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta)
    &\propto \exp\left[-\frac{1}{2}\left\{
    \mathbf{w}^{\mathrm{T}}\left(\alpha\mathbf{I}+\beta\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)\boldsymbol{\phi}(x_n)^{\mathrm{T}}\right)\mathbf{w}\right.\right. \\
    &\qquad\qquad\qquad\qquad\quad
    \left.\left.-2\beta\mathbf{w}^{\mathrm{T}}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n
    \right\}\right].
\end{aligned}
\end{equation}

Define

\begin{equation}
    \mathbf{S}^{-1} = \alpha\mathbf{I} + \beta\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)\boldsymbol{\phi}(x_n)^{\mathrm{T}}.
\end{equation}

At this point, the posterior has the form

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta)\propto\exp
    \left[-\frac{1}{2}
    \left(\mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} - 2\beta\mathbf{w}^{\mathrm{T}}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n\right)
    \right].
\end{equation}

We now want to rewrite the expression inside the exponential as a quadratic centered at some vector $\mathbf{m}_N$. We introduce $\mathbf{m}_N$ as the vector that will become the center, and therefore the mean, of the posterior Gaussian. A quadratic centered at $\mathbf{m}_N$ has the form

\begin{equation}
    (\mathbf{w}-\mathbf{m}_N)^{\mathrm{T}}\mathbf{S}^{-1}(\mathbf{w}-\mathbf{m}_N).
\end{equation}

Expanding this expression gives

\begin{equation}
\begin{aligned}
    (\mathbf{w}-\mathbf{m}_N)^{\mathrm{T}}\mathbf{S}^{-1}(\mathbf{w}-\mathbf{m}_N)
    &=
    \mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} - \mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N \\
    &\quad
    - \mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} + \mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N.
\end{aligned}
\end{equation}

Because $\mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w}$ is a scalar, its tranpose is equal to itself, and because $\mathbf{S}^{-1}$ is symmetric,

\begin{equation}
    \mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} = \mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N,
\end{equation}

so

\begin{equation}
    (\mathbf{w}-\mathbf{m}_N)^{\mathrm{T}}\mathbf{S}^{-1}(\mathbf{w}-\mathbf{m}_N) = \mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} - 2\mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N + \mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N.
\end{equation}

We now choose $\mathbf{m}_N$ so that the linear term in $\mathbf{w}$ matches the linear term in the posterior. To let

\begin{equation}
    -2\mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N = -2\beta\mathbf{w}^{\mathrm{T}}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n,
\end{equation}

we require

\begin{equation}
    \mathbf{S}^{-1}\mathbf{m}_N = \beta\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n.
\end{equation}

Multiplying both sides by $\mathbf{S}$ gives

\begin{equation}
    \mathbf{m}_N = \beta\mathbf{S}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n.
\end{equation}

Thus, $\mathbf{m}_N$ is chosen precisely so that the original quadratic expression in $\mathbf{w}$ can be written as a quadratic centered at $\mathbf{m}_N$. Using this choice,

\begin{equation}
\begin{aligned}
    \mathbf{w}^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{w} - 2\beta\mathbf{w}^{\mathrm{T}}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n
    &=
    (\mathbf{w}-\mathbf{m}_N)^{\mathrm{T}}\mathbf{S}^{-1}(\mathbf{w}-\mathbf{m}_N) \\
    &\quad
    -\mathbf{m}_N^{\mathrm{T}}\mathbf{S}^{-1}\mathbf{m}_N.
\end{aligned}
\end{equation}

The final term does not depend on $\mathbf{w}$, so it is absorbed into the normalization constant. Therefore,

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta)\propto\exp\left[-\frac{1}{2}(\mathbf{w}-\mathbf{m}_N)^{\mathrm{T}}\mathbf{S}^{-1}(\mathbf{w}-\mathbf{m}_N)\right].
\end{equation}

This is the form of a multivariate Gaussian centered at $\mathbf{m}_N$. Hence,

\begin{equation}
    p(\mathbf{w}\mid\mathbf{x},\mathbf{t},\alpha,\beta) = \mathcal{N}\left(\mathbf{w};\mathbf{m}_N,\mathbf{S}\right),
\label{eq:c1_parameter_bayesian_posterior}
\end{equation}

so $\mathbf{m}_N$ is the posterior mean and $\mathbf{S}$ is the posterior covariance.

Substituting the Gaussian observation model and Gaussian posterior into the predictive distribution in Eq.~\ref{eq:c1_bayesian_predictive_distribution} gives

\begin{equation}
    p(t\mid x,\mathbf{x},\mathbf{t}) = \int\mathcal{N}\left(t;\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x),\beta^{-1}\right)\mathcal{N}\left(\mathbf{w};\mathbf{m}_N,\mathbf{S}\right)\,d\mathbf{w},
\end{equation}

For a fixed input $x$, the feature vector $\boldsymbol{\phi}(x)$ is fixed. Because the posterior distribution of $\mathbf{w}$ is a Gaussian given in Eq.~\ref{eq:c1_parameter_bayesian_posterior}, a linear transformation of $\mathbf{w}$ is also a Gaussian,

\begin{equation}
    p(\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x)\mid\mathbf{x},\mathbf{t},\alpha,\beta) = \mathcal{N} \left(\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x); \mathbf{m}_N^{\mathrm{T}}\boldsymbol{\phi}(x),\boldsymbol{\phi}(x)^{\mathrm{T}}\mathbf{S}\boldsymbol{\phi}(x)\right).
\label{eq:c1_feature_posterior}
\end{equation}

To see where these parameters come from, the mean of the transformed variable is

\begin{equation}
    \mathbb{E}_{\mathbf{w}}\left[\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x)\right] = \mathbb{E}_{\mathbf{w}}[\mathbf{w}]^{\mathrm{T}} \boldsymbol{\phi}(x) = \mathbf{m}_N^{\mathrm{T}}\boldsymbol{\phi}(x),
\end{equation}

and its variance is

\begin{equation}
    \operatorname{var}_{\mathbf{w}}\left[\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x)\right] = \boldsymbol{\phi}(x)^{\mathrm{T}}\operatorname{cov}[\mathbf{w}]\boldsymbol{\phi}(x) = \boldsymbol{\phi}(x)^{\mathrm{T}}\mathbf{S}\boldsymbol{\phi}(x).
\end{equation}

When we rewrite the Gaussian model in Eq.~\ref{eq:c1_polynomial_bayesian_model} as

\begin{equation}
    t(x) = \mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x) + \epsilon, \qquad \mathrm{with} \quad \epsilon \sim \mathcal{N}(0,\beta^{-1}),
\end{equation}

We see that $t(x)$ is the sum of two independent Gaussian random variables, with the distribution of $\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x)$ given in Eq.~\ref{eq:c1_feature_posterior}. Therefore, $t(x)$ is itself Gaussian.

The predictive mean is:

\begin{equation}
    m(x) = \mathbb{E}[t(x)] = \mathbf{m}_N^{\mathrm{T}}\boldsymbol{\phi}(x) + 0 = \beta\boldsymbol{\phi}(x)^{\mathrm{T}}\mathbf{S}\sum_{n=1}^{N}\boldsymbol{\phi}(x_n)t_n.
\label{eq:c1_bayesian_predictive_distribution_mean}
\end{equation}

Similarly, because the two terms are independent, their variances add,

\begin{equation}
    s^2(x) = \operatorname{var}[t(x)] = \operatorname{var}\left[\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(x)\right] + \operatorname{var}[\epsilon] = \boldsymbol{\phi}(x)^{\mathrm{T}}\mathbf{S}\boldsymbol{\phi}(x) + \beta^{-1}.
\label{eq:c1_bayesian_predictive_distribution_var}
\end{equation}

Therefore, the predictive distribution becomes

\begin{equation}
    p(t\mid x,\mathbf{x},\mathbf{t}) = \mathcal{N}\left(t;m(x),s^2(x)\right),
\end{equation}

where $m(x)$ and $s^2(x)$ are given in Eq.~\ref{eq:c1_bayesian_predictive_distribution_mean} and Eq.~\ref{eq:c1_bayesian_predictive_distribution_var}

The predictive variance has two distinct sources,

\begin{equation}
    s^2(x) = \underbrace{\boldsymbol{\phi}(x)^{\mathrm{T}}\mathbf{S}\boldsymbol{\phi}(x)}_{\text{parameter uncertainty}} + \underbrace{\beta^{-1}}_{\text{observation noise}}.
\end{equation}

This decomposition is a key distinction between point-estimate and fully Bayesian prediction. A maximum likelihood prediction with fixed $\mathbf{w}_{\mathrm{ML}}$ accounts only for observation noise, whereas the Bayesian predictive distribution additionally accounts for uncertainty in the model parameters. As more informative training data are observed, the posterior covariance $\mathbf{S}$ of the parameter typically decreases, reducing the contribution from parameter uncertainty while the irreducible observation-noise variance $\beta^{-1}$ remains.

\section{Model Selection}

Model selection concerns choosing the model class and its effective complexity. Because training error is optimistically biased and generally decreases as model flexibility increases, model selection must be based on data not used to fit the candidate model.

When data is scarce, a common procedure is to first split the full data set into a \textit{training set} and a held-out \textit{test set}. Model selection is then performed using only the training set. With $S$-fold cross-validation, the training set is partitioned into $S$ folds; for each fold, the model is fitted on $S-1$ folds and evaluated on the remaining fold. If $E_s$ denotes the validation error on fold $s$, the cross-validation estimate is

\begin{equation}
    E_{\mathrm{CV}} = \frac{1}{S}\sum_{s=1}^{S} E_s.
\end{equation}

After selecting the model, it is typically refitted using the entire training set and evaluated once on the held-out test set.

The special case $S=N$, where $N$ is the number of training observations, is \textit{leave-one-out cross-validation}. The main disadvantage of cross-validation is computational cost since every candidate model must be trained $S$ times.

An alternative is to augment goodness of fit with an explicit complexity penalty. For example, the Akaike information criterion can be written as

\begin{equation}
    \mathrm{AIC} = -2\ln p(\mathcal{D}\mid\mathbf{w}_{\mathrm{ML}}) + 2M,
\end{equation}

where $M$ is the number of trainable parameters. The negative log-likelihood term rewards fit to the observed data, while the second term penalizes model complexity.

A variant of this quantity, called the \textit{Bayesian information criterion (BIC)}, will be discussed in Chapter 4. A fully Bayesian approach to model comparison, introduced in Chapter 3, provides a more principled treatment of model selection by integrating over parameter uncertainty, so that model complexity is controlled implicitly rather than through an explicit penalty term.

\section{The curse of dimensionality}

In practical pattern-recognition problems, the input $\mathbf{x}$ is often high-dimensional. As the dimensionality $D$ increases, the volume of the input space grows extremely rapidly, so a fixed number of training observations becomes increasingly sparse relative to the space that must be represented. This phenomenon is known as the \textit{curse of dimensionality}.

A simple illustration is obtained by partitioning each input dimension into $K$ intervals. In one dimension this produces $K$ cells, in two dimensions $K^2$ cells, and in $D$ dimensions

\begin{equation}
    N_{\mathrm{cells}} = K^D.
\end{equation}

Thus, maintaining the same spatial resolution in every dimension requires a number of cells that grows exponentially with $D$. A classifier that assigns a test point according to the training observations lying in the same cell therefore requires an exponentially increasing amount of data merely to prevent most cells from becoming empty. Local methods based on nearby observations encounter the same underlying problem because neighborhoods become increasingly sparsely populated as $D$ grows.

The curse of dimensionality also appears in parametric models because the number of distinct terms needed to represent interactions among the input variables can grow very rapidly with the input dimension $D$. Suppose that

\begin{equation}
    \mathbf{x} = (x_1,\ldots,x_D)^{\mathrm{T}}
\end{equation}

contains $D$ input variables, and consider a polynomial model containing all terms up to total degree three,

\begin{equation}
    y(\mathbf{x},\mathbf{w}) = w_0 + \sum_{i=1}^{D} w_i x_i + \sum_{i=1}^{D}\sum_{j=1}^{D} w_{ij}x_i x_j + \sum_{i=1}^{D}\sum_{j=1}^{D}\sum_{k=1}^{D}w_{ijk}x_i x_j x_k.
\end{equation}

The linear part contains $D$ distinct terms,

\begin{equation}
    x_1,\;x_2,\;\ldots,\;x_D.
\end{equation}

At first sight, the quadratic double sum appears to contain $D^2$ terms because there are $D$ possible values for $i$ and $D$ possible values for $j$. However, products such as $x_i x_j$ are invariant under permutations of their indices. Thus, their coefficients can be combined into a single coefficient. As a result, there are $D$ squared terms and $\binom{D}{2}$ pairwise interaction terms, giving

\begin{equation}
    N_2 = D+\binom{D}{2} = D + \frac{D(D-1)}{2} = \binom{D+1}{2}
\end{equation}

distinct monomials of degree two.

More generally, a monomial of total degree $m$ in $D$ variables has the form

\begin{equation}
    x_1^{a_1}x_2^{a_2}\cdots x_D^{a_D}, \qquad a_i \in \{0,1,2,\ldots,m\}.
\end{equation}

subject to

\begin{equation}
\sum_{i=1}^{D} a_i=m.
\end{equation}

The number of nonnegative integer solutions to this equation is

\begin{equation}
    N_m = \binom{D+m-1}{m}.
\end{equation}

If the polynomial contains all monomials from degree $0$ through degree $M$, the total number of independent coefficients is therefore

\begin{equation}
    N_{\mathrm{coeff}} = \sum_{m=0}^{M}\binom{D+m-1}{m} = \binom{D+M}{M}.
\end{equation}

For a cubic polynomial, $M=3$, so

\begin{equation}
    N_{\mathrm{coeff}} = \binom{D+3}{3} = \frac{(D+3)(D+2)(D+1)}{6}.
\end{equation}

Thus, even though the compact polynomial expression contains sums with $D$, $D^2$, and $D^3$ indexed terms, the number of  coefficients is smaller. Nevertheless, the number of coefficients still grows rapidly with dimension $D$. When $D$ is large compared with a fixed polynomial order $M$, each factor in the numerator is approximately $D$, giving

\begin{equation}
    \binom{D+M}{M} \sim \frac{D^M}{M!}.
\end{equation}

Hence, for a fixed polynomial order $M$, the number of parameters grows approximately as $D^M$. The growth is therefore polynomial rather than exponential in $D$. However, it can still become prohibitively large even for moderately high-dimensional inputs.

This exmaple is one manifestation of the curse of dimensionality. Increasing the number of input variables does not merely enlarge the input space; it can also cause the number of parameters required to represent interactions among those variables to grow combinatorially. As the number of parameters increases, more data are generally required for reliable estimation and it increases both the computational cost and the risk of overfitting.

A closely related high-dimensional effect appears even for a simple isotropic Gaussian distribution. Consider the $D$-dimensional standard Gaussian

\begin{equation}
    p(\mathbf{x}) = \frac{1}{(2\pi)^{D/2}}\exp\left(-\frac{1}{2}\mathbf{x}^{\mathrm{T}}\mathbf{x}\right),
\end{equation}

where $\mathbf{x}\in\mathbb{R}^D$. The distance of $\mathbf{x}$ from the origin is

\begin{equation}
    r = \|\mathbf{x}\| = \sqrt{\mathbf{x}^{\mathrm{T}}\mathbf{x}}.
\end{equation}

The density at any individual point depends only on its distance from the origin,

\begin{equation}
    p(\mathbf{x}) = \frac{1}{(2\pi)^{D/2}}\exp\left(-\frac{r^2}{2}\right).
\end{equation}

The density is therefore largest at $r=0$ and decreases exponetially as $r$ increases. However, this does not mean that most of the probability mass lies near the origin. The reason is that probability mass depends on both the density at each point and the number of points available at a given radius.

To see this, consider a thin spherical shell with radius $r$ and thickness $dr$. All points in this shell have approximately the same Gaussian density because they have approximately the same value of $r$. The probability mass in the shell is therefore approximately

\begin{equation}
    p_r(r)\,dr = p(\mathbf{x}) \times \text{surface area of the sphere at radius } r \times dr.
\end{equation}

The surface area of a $D$-dimensional sphere of radius $r$ is

\begin{equation}
    A_D(r) = \frac{2\pi^{D/2}}{\Gamma(D/2)} r^{D-1}.
\end{equation}

Therefore,

\begin{align}
    p_r(r)
    &= A_D(r)\frac{1}{(2\pi)^{D/2}}\exp\left(-\frac{r^2}{2}\right) \\
    &= \frac{1}{2^{D/2-1}\Gamma(D/2)}r^{D-1}\exp\left(-\frac{r^2}{2}\right), \qquad r\geq 0.
\end{align}

The Gaussian factor $\exp(-r^2/2)$ decreases as $r$ increases, because individual points farther from the origin have lower density. In contrast, the geometric factor $r^{D-1}$ increases rapidly with $r$, because the surface area of a high-dimensional sphere increases rapidly with radius. The radial probability density $p_r(r)$ is determined by the competition between these two effects.

To find the radius at which the probability mass is most concentrated, we maximize $p_r(r)$. This is equivalent to maximizing its logarithm,

\begin{equation}
    \ln p_r(r) = (D-1)\ln r - \frac{r^2}{2} + \mathrm{const}.
\end{equation}

Differentiating with respect to $r$ gives

\begin{equation}
    \frac{d}{dr}\ln p_r(r) = \frac{D-1}{r} - r.
\end{equation}

Setting the derivative equal to zero gives

\begin{equation}
    r_{\mathrm{mode}} = \sqrt{D-1}.
\end{equation}

For $D=1$, the probability mass is concentrated most strongly at the center, $r=0$. For $D=2$, the largest amount of probability mass per small change in radius lies on a ring at $r=1$. In higher dimensions, most of the probability mass is concentrated in a thin spherical shell located farther from the origin at $r=\sqrt{D-1}$. Although each individual point in this thin shell has a much lower density than the origin, the shell contains vastly more points, so it contains much more total probability mass.

The curse of dimensionality does not, however, imply that learning from high-dimensional data is necessarily impossible. The key reason is that real data often do not occupy the entire $D$-dimensional space. Instead, they may be concentrated near a much lower-dimensional subset. If the possible observations can be described by only $d$ independent degrees of freedom, with $d\ll D$, then the data may lie approximately on a $d$-dimensional manifold embedded in $\mathbb{R}^D$. The quantity $d$ is referred to as the \textit{intrinsic dimensionality} of the data.

For example, an image containing $D$ pixels can be represented as

\begin{equation}
    \mathbf{x} = (x_1,\ldots,x_D)^{\mathrm{T}},
\end{equation}

so the image is formally a point in $\mathbb{R}^D$. However, suppose all images contain the same object and differ only in horizontal position, vertical position, and orientation. Although the pixel representation may have thousands of dimensions, the variability among the images is controlled primarily by only three quantities. The set of valid images might therefore occupy a structure with intrinsic dimension close to three within the much larger pixel space. This distinction is important because a learning algorithm need not model the entire space $\mathbb{R}^D$, but only the much smaller structure in which the data are concentrated. Modern dimensionality-reduction and representation-learning methods attempt to discover or exploit such low-dimensional structure.

A second property that can reduce the practical severity of the curse of dimensionality is \textit{smoothness}. Suppose that a target is represented by a function $f(\mathbf{x})$. A smoothness assumption states, roughly, that nearby inputs tend to produce similar outputs,

\begin{equation}
\|\mathbf{x}-\mathbf{x}'\|\ \text{small}
\quad\Longrightarrow\quad
|f(\mathbf{x})-f(\mathbf{x}')|\ \text{small}.
\end{equation}

Under this assumption, observing the target at one point provides useful information about the target at nearby points. Therefore, smoothness allows nearby observations to share predictive information.

\textit{Sparsity} assumes that only a relatively small subset of the available variables, features, or model parameters is needed to describe the relevant structure in the data. For example, even if an input $\mathbf{x}\in\mathbb{R}^D$ contains a very large number of features, the target may depend strongly on only a small subset of them. Similarly, a model may contain a large parameter vector $\mathbf{w}$ while only a small number of entries are substantially different from zero. By reducing the number of active variables or parameters, sparsity lowers the effective number of degrees of freedom that must be estimated from data and can improve generalization. Common mechanisms for encouraging sparsity include feature selection and regularization methods such as $L_1$ regularization.

\textit{Locality} assumes that interactions are strongest among inputs that are close according to some appropriate notion of neighborhood, while distant inputs interact weakly or not at all. This reduces the need to model arbitrary interactions among all components of a high-dimensional input. For example, in an image, nearby pixels are often much more strongly related than pixels located far apart. A model can therefore restrict each unit to operate only on a local region rather than on the entire input. If each local computation involves only $k$ nearby variables with $k\ll D$, then the effective dimensionality of each interaction is much smaller than the full ambient dimension. Locality is exploited explicitly in methods such as convolutional neural networks, nearest-neighbor methods, and local kernel models.

\textit{Parameter sharing} reduces model complexity by using the same parameters across multiple locations or parts of the input rather than learning a separate set of parameters for each one. Convolutional neural networks provide a standard example, where the same convolutional filter is repeatedly applied across the entire spatial domain. This substantially reduces the number of trainable parameters, imposes useful structural constraints on the model, and allows knowledge learned in one region of the input to generalize to other regions.

Therefore, successful learning in high-dimensional spaces generally relies on some form of structure or property in the data and/or model. It could include low intrinsic dimensionality, smoothness, sparsity, locality, parameter sharing, and other constraints that reduce the effective complexity of the learning problem relative to the nominal ambient dimension $D$.

\section{Decision Theory}

Probability theory provides a mathematical framework for representing and manipulating uncertainty, but in many pattern recognition problems the ultimate objective is not merely to estimate probabilities. Instead, we must use those probabilities to make a decision. Decision theory provides the framework for selecting an action when the quantities of interest are uncertain, thereby connecting probabilistic inference with prediction and decision making.

Suppose we observe an input vector $\mathbf{x}$ and wish to predict a corresponding target variable $t$. In regression problems, $t$ is typically continuous, whereas in classification problems it represents a discrete class label. The joint distribution $p(\mathbf{x},t)$ provides a complete probabilistic description of the relationship between inputs and targets. Estimating such a distribution from training data is an \textit{inference} problem. Once the relevant probability distribution has been obtained, however, we must still determine what prediction or action should be taken for a particular input $\mathbf{x}$. This second stage is the \textit{decision} problem.

For classification, suppose the target belongs to one of $K$ classes $\{C_1,\ldots,C_K\}$. Given an observed input $\mathbf{x}$, Bayes' theorem gives the posterior probability of class $C_k$ as

\begin{equation}
    p(C_k\mid\mathbf{x}) = \frac{p(\mathbf{x}\mid C_k)p(C_k)}{p(\mathbf{x})} = \frac{p(\mathbf{x}\mid C_k)p(C_k)}{\sum_{j=1}^{K} p(\mathbf{x}\mid C_j)p(C_j)}.
\end{equation}

Here, $p(C_k)$ is the prior probability of class $C_k$, representing our uncertainty about the class before observing $\mathbf{x}$. The likelihood $p(\mathbf{x}\mid C_k)$ describes how probable the observed input is under class $C_k$. The posterior probability $p(C_k\mid\mathbf{x})$ is the probability of class $C_k$ after incorporating the information contained in $\mathbf{x}$. The denominator normalizes the posterior probabilities so that they sum to one over all classes.

The posterior probabilities themselves do not yet specify what action should be taken. A decision rule must map the observed input, or equivalently the posterior probabilities associated with that input, to a particular action. In the simplest classification setting, where every incorrect classification is treated equally, we will show that minimizing the expected loss is equivalent to assigning $\mathbf{x}$ to the class with the largest posterior probability. In many applications, the appropriate decision rule depends not only on the posterior probabilities, but also on the loss associated with each possible error. When different misclassifications have different consequences, the optimal decision is therefore the one that minimizes the expected loss rather than simply the probability of error.

\subsection{Minimizing the Misclassification Rate}

We first assume that all types of errors have the same consequence. As a result, the objective of a classification problem is to minimize the probability of assigning an input to the wrong class. A decision rule assigns every possible input $\mathbf{x}$ to one of the $K$ classes $\{C_1,\ldots,C_K\}$. This partitions the input space into \textit{decision regions} $\{\mathcal{R}_1,\ldots,\mathcal{R}_K\}$, where every $\mathbf{x}\in\mathcal{R}_k$ is assigned to class $C_k$. The boundaries separating these regions are called \textit{decision boundaries} or \textit{decision surfaces}.

Now consider all inputs that fall in a particular region $\mathcal{R}_k$. The classifier assigns all of these inputs to class $C_k$. A classification error occurs whenever the true class is some $C_j$ with $j\neq k$. For one such class $C_j$, the probability of this type of error is

\begin{equation}
    p(\mathbf{x}\in\mathcal{R}_k,C_j) = \int_{\mathcal{R}_k}p(\mathbf{x},C_j)\,d\mathbf{x}.
\end{equation}

Because the true class could be any of the remaining $K-1$ classes, the contribution of region $\mathcal{R}_k$ to the total probability of misclassification is

\begin{equation}
    \sum_{j\neq k}\int_{\mathcal{R}_k}p(\mathbf{x},C_j)\,d\mathbf{x} = \int_{\mathcal{R}_k}\sum_{j\neq k}p(\mathbf{x},C_j)\,d\mathbf{x}.
\end{equation}

Finally, summing this error probability over all decision regions gives the total probability of misclassification,

\begin{equation}
    p(\mathrm{mistake}) = \sum_{k=1}^{K}\int_{\mathcal{R}_k}\sum_{j\neq k}p(\mathbf{x},C_j)\,d\mathbf{x}.
\end{equation}

Because we place no restrictions on the form of the decision rule, the class assigned at one value of $\mathbf{x}$ can be chosen independently of the class assigned at another value of $\mathbf{x}$. The collection of these individual assignments then determines the decision regions. For a given $\mathbf{x}$, we choose the class $C_k$ that minimize the local contribution to the misclassification probability

\begin{equation}
    \sum_{j\neq k} p(\mathbf{x},C_j) = p(\mathbf{x})-p(\mathbf{x},C_k).
\end{equation}

Because $p(\mathbf{x})$ is the same for every class at a fixed $\mathbf{x}$, minimizing this error contribution is equivalent to maximizing $p(\mathbf{x},C_k)$. Thus, each $\mathbf{x}$ should be assigned to the class with the largest joint probability,

\begin{equation}
    \hat{C}(\mathbf{x}) = \arg\max_{C_k} p(\mathbf{x},C_k).
\end{equation}

Using the product rule,

\begin{equation}
    p(\mathbf{x},C_k) = p(C_k\mid\mathbf{x})p(\mathbf{x}),
\end{equation}

and again, because $p(\mathbf{x})$ does not depend on the class $C_k$, maximizing the joint probability $p(\mathbf{x},C_k)$ is equivalent to maximizing the posterior probability $p(C_k\mid\mathbf{x})$. Hence, the decision rule that minimizes the misclassification probability becomes

\begin{equation}
    \hat{C}(\mathbf{x}) = \arg\max_{C_k} p(C_k\mid\mathbf{x}).
\label{eq:c1_maximum_posterior_classification_rule}
\end{equation}

The probability of making a correct classification is

\begin{equation}
    p(\mathrm{correct}) = \sum_{k=1}^{K}p(\mathbf{x}\in\mathcal{R}_k,C_k) = \sum_{k=1}^{K}\int_{\mathcal{R}_k}p(\mathbf{x},C_k)\,d\mathbf{x}.
\end{equation}

It can also be shown that maximizing $p(\mathrm{correct})$ is equivalent to minimizing $p(\mathrm{mistake})$. In both cases, the optimal decision is obtained by assigning $\mathbf{x}$ to the class with the largest posterior probability, as in Eq.~\ref{eq:c1_maximum_posterior_classification_rule}. The resulting decision boundaries occur where the posterior probabilities of competing classes are equal.

\subsection{Minimizing the Expected Loss}

To account for different consequences associated with different types of errors, we introduce a \textit{loss function}. Suppose that the true class is $C_k$ and the classifier assigns the input $\mathbf{x}$ to class $C_j$. We denote the loss associated with this outcome by $L_{kj}$. The collection of these values forms a \textit{loss matrix}, where the element $L_{kj}$ specifies the cost of assigning an observation from the true class $C_k$ to class $C_j$. Typically, $L_{kk}=0$ if a correct classification incurs no loss, whereas the off-diagonal elements are postive and may differ depending on the consequences of different types of misclassification.

Let $\mathcal{R}_j$ denote the decision region for class $C_j$, so that every $\mathbf{x}\in\mathcal{R}_j$ is assigned to $C_j$. If the true class is $C_k$, the probability density associated with this outcome is $p(\mathbf{x},C_k)$. Therefore, the expected loss contributed by assigning inputs in $\mathcal{R}_j$ to class $C_j$ when their true class is $C_k$ is

\begin{equation}
    \int_{\mathcal{R}_j}L_{kj}p(\mathbf{x},C_k)\,d\mathbf{x}.
\end{equation}

Summing over all true classes and all decision regions gives the total expected loss,

\begin{equation}
    \mathbb{E}[L] = \sum_{j}\sum_{k}\int_{\mathcal{R}_j}L_{kj}p(\mathbf{x},C_k)\,d\mathbf{x} = \sum_{j}\int_{\mathcal{R}_j}\sum_{k}L_{kj}p(\mathbf{x},C_k)\,d\mathbf{x} .
\end{equation}

As before, if no restrictions are placed on the form of the decision rule, the class assigned at one value of $\mathbf{x}$ can be chosen independently of the class assigned at another value. Therefore, minimizing the total expected loss can be done separately for each $\mathbf{x}$. If $\mathbf{x}$ is assigned to class $C_j$, its local contribution to the expected loss is

\begin{equation}
    \sum_{k}L_{kj}p(\mathbf{x},C_k) = p(\mathbf{x})\sum_{k}L_{kj}p(C_k\mid\mathbf{x}).
\end{equation}

Because $p(\mathbf{x})$ is independent of the chosen class $C_j$, it does not affect which decision minimizes the loss. We therefore define the conditional expected loss associated with assigning $\mathbf{x}$ to class $C_j$ as

\begin{equation}
    R(C_j\mid\mathbf{x}) = \sum_{k}L_{kj}p(C_k\mid\mathbf{x}),
\end{equation}

where $R(C_j\mid\mathbf{x})$ is also commonly called the \textit{conditional risk}. The optimal decision rule assigns $\mathbf{x}$ to the class whose conditional expected loss is smallest,

\begin{equation}
    \hat{C}(\mathbf{x}) = \arg\min_{C_j}\sum_{k}L_{kj}p(C_k\mid\mathbf{x}).
\label{eq:c1_minimum_expected_loss_classification_rule}
\end{equation}

Thus, the posterior probabilities describe the uncertainty about the true class, and the loss matrix describes the consequences of the possible decisions. The optimal classifier combines both quantities and chooses the decision with the minimum expected loss.

We now show that the maximum-posterior classification rule in Eq.~\ref{eq:c1_maximum_posterior_classification_rule} is a special case of the more general minimum-expected-loss rule in Eq.~\ref{eq:c1_minimum_expected_loss_classification_rule} when all misclassification errors have the same loss. Let

\begin{equation}
    L_{kj} =
    \begin{cases}
        0, & k=j,\\
        L, & k\neq j,
    \end{cases}
\end{equation}

where $L>0$ is the common loss assigned to any incorrect classification. If $\mathbf{x}$ is assigned to class $C_j$, the corresponding conditional expected loss is

\begin{equation}
    \sum_k L_{kj}p(C_k|\mathbf{x}) = L\sum_{k\neq j}p(C_k|\mathbf{x}) = L\left[1-p(C_j|\mathbf{x})\right],
\end{equation}

Since $L$ is a positive constant and is the same for every candidate class, minimizing the conditional expected loss is equivalent to maximizing $p(C_j|\mathbf{x})$. Therefore, under equal misclassification losses, the decision rule in Eq.~\ref{eq:c1_minimum_expected_loss_classification_rule} reduces to Eq.~\ref{eq:c1_maximum_posterior_classification_rule}.

\subsection{The Reject Option}

Classification errors are most likely to occur for inputs $\mathbf{x}$ for which no class has a dominant posterior probability. In such regions, the largest value among $\{p(C_1\mid\mathbf{x}),\ldots,p(C_K\mid\mathbf{x})\}$ is substantially below one, indicating considerable uncertainty about the true class. Instead of forcing the classifier to make a decision for every input, we can introduce a \textit{reject option}, under which sufficiently uncertain inputs are left unclassified.

Let

\begin{equation}
    p_{\max}(\mathbf{x}) = \max_k p(C_k\mid\mathbf{x})
\end{equation}

denote the largest posterior probability at input $\mathbf{x}$. Given a rejection threshold $\theta$, the classifier makes a class prediction only when $p_{\max}(\mathbf{x}) > \theta$, and rejects the input otherwise. Equivalently, the decision rule can be written as

\begin{equation}
    \hat{C}(\mathbf{x}) =
    \begin{cases}
        \displaystyle \arg\max_{C_k} p(C_k\mid\mathbf{x}), & \text{if } \max_k p(C_k\mid\mathbf{x}) \ge \theta,\\
        \mathrm{reject}, & \text{otherwise}.
    \end{cases}
\end{equation}

The threshold $\theta$ controls the trade-off between the fraction of inputs that can be classified and the uncertainty associated with those decisions. Increasing $\theta$ requires greater posterior confidence before a prediction is accepted, so more inputs are rejected but the remaining accepted classifications tend to have a lower error rate. Conversely, decreasing $\theta$ results in fewer rejections but allows decisions to be made in more uncertain regions of the input space.

Because the posterior probabilities satisfy

\begin{equation}
    \sum_{k=1}^{K} p(C_k\mid\mathbf{x}) = 1,
\end{equation}

the largest posterior probability must satisfy

\begin{equation}
    \max_k p(C_k\mid\mathbf{x}) \geq \frac{1}{K}.
\end{equation}

Therefore, choosing $\theta < 1/K$ guarantees that no input is rejected, whereas choosing $\theta=1$ causes all inputs to be rejected except the degenerate case in which one posterior probability is exactly one.

The reject option can also be incorporated into the minimum-expected-loss framework by treating rejection as an additional action. Let $L_{kr}$ denote the loss incurred when the true class is $C_k$ and the classifier rejects the input. The conditional expected loss of rejection is then

\begin{equation}
    R(\mathrm{reject}\mid\mathbf{x}) = \sum_k L_{kr}p(C_k\mid\mathbf{x}).
\end{equation}

For each input $\mathbf{x}$, the classifier compares this quantity with the conditional expected loss of assigning $\mathbf{x}$ to each class,

\begin{equation}
    R(C_j\mid\mathbf{x}) = \sum_k L_{kj}p(C_k\mid\mathbf{x}).
\end{equation}

The input is rejected whenever the expected loss of rejection is smaller than that of every class assignment; otherwise, it is assigned to the class with the smallest conditional expected loss. In this way, rejection provides a principled mechanism for avoiding highly uncertain decisions when the cost of abstaining is smaller than the expected cost of making a potentially incorrect classification.

\subsection{Inference and Decision}

We have broken the classiﬁcation problem down into two separate stages, the \textit{inference} stage, in which training data are used to estimate the posterior probabilities $p(C_k\mid\mathbf{x})$, and a \textit{decision} stage, in which these probabilities are used to make class assignments. Alternatively, the two stages can be combined by learning a function that maps $\mathbf{x}$ directly to a decision. Such a function is called a \textit{discriminant function}.

There are three main approaches to classification, differing in which probabilistic quantities are modeled. These are given in decreasing order of complexity by:

\begin{enumerate}
    \item The first approach is to model the class-conditional density $p(\mathbf{x}\mid C_k)$ for each class together with the prior class probability $p(C_k)$. The prior $p(C_k)$ can typically be estimated from the relative frequency of class $C_k$ in the training data, Bayes' theorem is then used to obtain the posterior probability,

    \begin{equation}
        p(C_k\mid\mathbf{x}) = \frac{p(\mathbf{x}\mid C_k)p(C_k)}{\sum_k p(\mathbf{x}\mid C_k)p(C_k)},
    \end{equation}

    Equivalently, we may model the joint distribution $p(\mathbf{x},C_k)$ directly for each class and normalize it over all classes to obtain $p(C_k\mid\mathbf{x})$. Once the posterior probabilities are available, decision theory is used to determine the class assignment. Approaches that explicitly or implicitly model the joint distribution $p(\mathbf{x},C_k)$ are called \textit{generative models}. From such a model, synthetic inputs can be generated by first sampling a class from $p(C_k)$ and then sampling from $p(\mathbf{x}\mid C_k)$. Examples of this approach include linear and quadratic discriminant analysis (LDA and QDA), Naive Bayes classifiers, Gaussian mixture classifiers, Bayesian network classifiers, and hidden Markov model classifiers.

    \item The second approach is to model the posterior class probabilities $p(C_k\mid\mathbf{x})$ directly, without separately modeling $p(\mathbf{x}\mid C_k)$ and $p(C_k)$. The resulting posterior probabilities are then passed to the decision stage in exactly the same way as before. Models that directly estimate $p(C_k\mid\mathbf{x})$ are called \textit{discriminative models}. Examples of this approach include (multinomial) logistic regression, neural networks with sigmoid or softmax outputs.

    \item The third approach removes the probabilistic inference stage altogether. Instead, we learn a \textit{discriminant function} $f(\mathbf{x})$ that maps the input directly to a class label or decision. In this case, the model learns the decision boundary directly. Examples of this approach include the perceptron, Fisher's linear discriminant, nearest-neighbor classifiers, and nearest-centroid classifiers, which can be trained to separate classes without explicitly modeling class posterior probabilities.

\end{enumerate}

The three approaches differ in both statistical and computational requirements. The first approach is the most demanding because when $\mathbf{x}$ is high-dimensional, accurately estimating $p(\mathbf{x}\mid C_k)$, or equivalently $p(\mathbf{x},C_k)$ can require a large amount of training data. However, once these distributions are estimated, they also determine the marginal input distribution,

\begin{equation}
    p(\mathbf{x}) = \sum_k p(\mathbf{x}\mid C_k)p(C_k).
\end{equation}

This allows the model to identify inputs having very small probability under the training distribution, which can be useful for \textit{outlier detection} or \textit{novelty detection}. However, if the goal is only classification, modeling the full distribution of $\mathbf{x}$ may be unnecessarily difficult because much of the structure in $p(\mathbf{x}\mid C_k)$ may have little effect on $p(C_k\mid\mathbf{x})$. In such cases, directly modeling the posterior probabilities can be more efficient.

The third approach simplifies the problem further by learning a discriminant function that maps $\mathbf{x}$ directly to a class decision, thereby avoiding explicit estimation of both $p(\mathbf{x}\mid C_k)$ and $p(C_k\mid\mathbf{x})$. However, it does not provide posterior probabilities, which are useful for several reasons.

First, posterior probabilities allow the decision rule to be changed without retraining the model. For example, if the loss matrix changes, the new minimum-risk decision can be obtained directly from

\begin{equation}
    \hat{C}(\mathbf{x}) = \arg\min_{C_j}\sum_k L_{kj}p(C_k\mid\mathbf{x}).
\end{equation}

whereas a discriminative function may instead need to be retrained.

Second, posterior probabilities support the reject option by quantifying classification uncertainty. Inputs for which the largest posterior probability is too small can be rejected rather than forcibly classified.

Third, posterior probabilities make it possible to adjust for changes in the class priors. Because

\begin{equation}
    p(C_k\mid\mathbf{x}) \propto p(\mathbf{x}\mid C_k)p(C_k),
\end{equation}

the training priors can be replaced by the new priors, followed by renormalization across classes. This is useful when the training set has been artificially balanced or when the population class distribution is strongly imbalanced.

Finally, probabilistic outputs make it easier to combine information from multiple models or data sources. Suppose $M$ data sources provide observations $\mathbf{x}_1,\ldots,\mathbf{x}_M$, with one probabilistic model providing the posterior $p(C_k\mid\mathbf{x}_m)$ for each source $\mathbf{x}_m$. Assume that these sources are conditionally independent given the class $C_k$. The posterior conditioned on all sources is

\begin{equation}
\begin{aligned}
    p(C_k\mid\mathbf{x}_1,\ldots,\mathbf{x}_M)
    &\propto
    p(\mathbf{x}_1,\ldots,\mathbf{x}_M\mid C_k)p(C_k) \\
    &=
    p(C_k)\prod_{m=1}^{M}p(\mathbf{x}_m\mid C_k).
\end{aligned}
\end{equation}

Applying Bayes' theorem separately to the output of each model yields

\begin{equation}
    p(\mathbf{x}_m\mid C_k)
    \propto
    \frac{p(C_k\mid\mathbf{x}_m)}{p(C_k)}.
\end{equation}

Substituting these expressions into the joint posterior gives

\begin{equation}
\begin{aligned}
    p(C_k\mid\mathbf{x}_1,\ldots,\mathbf{x}_M)
    &\propto
    p(C_k)
    \prod_{m=1}^{M}
    \frac{p(C_k\mid\mathbf{x}_m)}{p(C_k)} \\
    &=
    p(C_k)^{1-M}
    \prod_{m=1}^{M}p(C_k\mid\mathbf{x}_m).
\end{aligned}
\end{equation}

Thus, if separate probabilistic models provide posterior probabilities from conditionally independent data sources, their outputs can be combined into a joint posterior that incorporates all available sources. This illustrates an important advantage of retaining posterior probabilities rather than learning only a direct input-to-class mapping.
